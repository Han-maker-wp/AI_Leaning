# 第 3 课：核心数据结构

> 🎬 开场钩子：`a, b = b, a`——一行代码、没有临时变量，交换完成。Java 里这是三步操作（temp = a; a = b; b = temp），Python 里它只是「解包」协议的自然结果。本课结束时，你不只知道这一行为什么成立，还能一眼读懂 `first, *rest = xs` 这种乍看像「抢劫」的赋值语句。

## 3.1 一张表选型：Python 内置结构 vs Java 集合

| Python | Java 近似 | 可变 | 有序 | 典型用途 |
|---|---|---|---|---|
| `list` | ArrayList / 数组 | 是 | 是 | 通用序列：样本列表、loss 历史 |
| `tuple` | `List.of(...)`（不可变列表） | 否 | 是 | 固定长度记录、多返回值、dict 的键 |
| `dict` | HashMap（3.7+ 保持插入序） | 是 | 插入序 | 配置项、JSON、指标名 → 值 |
| `set` | HashSet | 是 | 无序 | 去重、O(1) 成员判断、集合运算 |

> ☕ Java 视角：Python 把这四个结构做成了「语法级公民」——字面量直接写 `[1,2]`、`{"k": v}`，不需要 `new ArrayList<>()` 的仪式感。泛型不存在，一个 list 里混装不同类型在语法上合法（但别这么干，给自己找麻烦）。

## 3.2 list：主力容器

```python
losses = [0.9, 0.7, 0.5]
losses.append(0.4)          # 尾部追加 O(1)，等价 ArrayList.add
losses.extend([0.3, 0.25])  # 批量追加
losses.insert(0, 1.0)       # 指定位置插入 O(n)
last = losses.pop()         # 弹出并返回尾元素
losses.remove(1.0)          # 按值删除第一个匹配（找不到抛 ValueError）
print(losses[0], losses[-1])    # 负索引从尾部数，xs[-1] 即最后一个
print(len(losses), sum(losses), min(losses), max(losses))

print(0.4 in losses)        # 成员判断，list 是 O(n) 线性扫

sorted_losses = sorted(losses)   # 返回新列表
losses.sort(reverse=True)        # 原地排序（Java: list.sort(comparator)）
```

> ☕ Java 视角：`xs[-1]` 代替 `xs.get(xs.size() - 1)`；`sorted(xs)` 返回新列表、`xs.sort()` 原地改——这对区分「纯函数 / 副作用」很重要，ML 代码里如果误用原地操作，可能悄悄毁掉历史数据。

## 3.3 tuple：不可变序列与解包

```python
point = (3, 4)
x, y = point                    # 解包：Java 里只能 point[0] / point[1]
lo, hi = min(xs), max(xs)

a, b = 1, 2
a, b = b, a                     # 交换变量不需要中间变量

def min_max(xs):
    return min(xs), max(xs)     # 「多返回值」本质：返回一个 tuple

one = (42,)                     # 单元素 tuple 必须带逗号，(42) 只是括号表达式
```

解包还能带星号收集：`first, *rest = [1, 2, 3, 4]` 得到 `first=1, rest=[2,3,4]`。

什么时候用 tuple 而不是 list？固定结构（坐标、形状、超参组合）、要当 dict 键（可哈希必须不可变）、函数多返回值。ML 代码里数据形状一律用 tuple 表达，如 `X.shape == (150, 4)`。

> 🍿 彩蛋｜逗号才是灵魂：`(42)` 只是一个数字外加一对括号，`(42,)` 才是 tuple——单元素 tuple 必须带尾逗号，括号可以没有，逗号不能少。同款冷知识：`return 1, 2` 看似返回两个值，其实返回的是一个 tuple，接收方再靠解包拆开——一进一出，全靠逗号撑场面。

## 3.4 dict：键值对统治 Python 世界

```python
config = {"lr": 0.001, "epochs": 10}
config["batch_size"] = 32       # 新增/覆盖
print(config["lr"])             # 键不存在 → KeyError

print(config.get("wd"))         # 不存在 → None，不抛异常
print(config.get("wd", 0.0))    # 不存在 → 返回默认值 0.0

"lr" in config                  # 判断键是否存在（O(1)）

for key, value in config.items():
    print(key, value)
```

> ☕ Java 视角：`getOrDefault(k, v)` ≈ `d.get(k, v)`；`entrySet()` 遍历 ≈ `d.items()`。但 Python 的 dict 字面量 + 方括号访问写起来太顺，以至于「一切皆 dict」：模块命名空间、类属性、JSON、框架配置全是它。计数惯用法 `d[w] = d.get(w, 0) + 1` 请背下来。

## 3.5 set：去重与集合运算

```python
vocab = set(["train", "train", "eval", "test"])   # 自动去重
vocab = {"train", "eval", "test"}                 # 字面量（空集必须 set()，{} 是空 dict）
vocab.add("infer")
vocab.discard("infer")       # 不存在也不报错（remove 会报）

print("train" in vocab)      # O(1)——大集合成员判断比 list 快得多

a = {"a", "b", "c"}
b = {"b", "c", "d"}
print(a & b)     # 交集 {'b', 'c'}
print(a | b)     # 并集
print(a - b)     # 差集 {'a'}
```

## 3.6 切片：所有序列通用的子序列语法

```python
xs = list(range(10))        # [0, 1, ..., 9]
xs[2:5]     # [2, 3, 4]     含头不含尾：下标 2、3、4
xs[:3]      # [0, 1, 2]     开头取 3 个
xs[-3:]     # [7, 8, 9]     最后 3 个
xs[::2]     # [0, 2, 4, 6, 8]   步长 2
xs[::-1]    # [9, 8, ..., 0]   步长 -1 即反转
"abcdef"[1:4]               # 'bcd'，字符串同样适用
```

完整形式 `xs[start:stop:step]`，任何一项都可省略。切片返回**新对象**（浅拷贝）——`ys = xs[:]` 是惯用的浅拷贝写法。这套语法在 NumPy（第 7 课）里原样升级为多维版本，是 ML 代码的日常。

## 3.7 推导式（重点！）：一行完成「筛选 + 变换」

```python
values = [3, -1, 4, -1, 5, -9, 2, 6]

squares   = [v * v for v in values]               # 变换（map）
positives = [v for v in values if v > 0]          # 筛选（filter）
pos_sq    = [v * v for v in values if v > 0]      # 筛选 + 变换
zeroed    = [0 if v < 0 else v for v in values]   # 条件表达式放前半段

d = {name: 0.0 for name in ["loss", "acc"]}       # dict 推导式
s = {v % 3 for v in values}                       # set 推导式
```

读法：`[表达式 for 变量 in 序列 if 条件]`——语义上先过 if 再算表达式，等价于：

```python
result = []
for v in values:
    if v > 0:
        result.append(v * v)
```

> ☕ Java 视角：这就是 Stream API 的位置——`xs.stream().filter(x -> x > 0).map(x -> x * x).toList()`。区别是推导式语法更接近自然语序、没有「起流」成本，Python 社区用它用得极重，读 ML 代码十行里三行是推导式。嵌套两层以内可读，超过就改回 for 循环。

为什么现在就要练熟：第 7 课之后你会发现「对一批数据逐个算」到处都是，推导式是向量化之前的最佳过渡形态。

## 完整演示代码

与 `code/L03_data_structures.py` 相同：

```python
"""L03：核心数据结构演示。运行：python3 code/L03_data_structures.py"""


def main() -> None:
    # ---------- list：最常用的有序序列 ----------
    losses = [0.9, 0.7, 0.5, 0.4]
    losses.append(0.35)             # 尾部追加，O(1)
    losses.extend([0.3, 0.28])      # 批量追加
    print(f"losses = {losses}")
    print(f"最后一个 loss：{losses[-1]}")       # 负索引从尾部数
    print(f"最小 loss：{min(losses)}，最大：{max(losses)}")

    sorted_losses = sorted(losses)  # 返回新列表，不动原列表
    losses.sort()                   # 原地排序
    print(f"排序后：{losses}；副本：{sorted_losses}")

    # ---------- tuple：不可变序列，主打「解包」 ----------
    point = (3, 4)
    x, y = point                    # 解包：Java 里只能 point[0]/point[1]
    print(f"x={x}, y={y}")

    a, b = 1, 2
    a, b = b, a                     # 交换变量不需要中间变量
    print(f"交换后 a={a}, b={b}")

    def min_max(xs):
        return min(xs), max(xs)     # 「多返回值」本质是返回一个 tuple

    lo, hi = min_max(losses)
    print(f"min={lo}, max={hi}")

    # ---------- dict：键值对，ML 里的配置/指标全靠它 ----------
    config = {"lr": 0.001, "epochs": 10, "batch_size": 32}
    config["optimizer"] = "adam"    # 新增/覆盖
    print(f"lr = {config.get('lr')}")          # get 不存在返回 None
    print(f"wd = {config.get('wd', 0.0)}")     # get 带默认值，不抛 KeyError

    for key, value in config.items():          # 遍历键值对
        print(f"  {key} = {value}")

    # ---------- set：去重与集合运算 ----------
    tokens = ["train", "train", "eval", "test", "eval"]
    vocab = set(tokens)             # 去重
    print(f"去重后 vocab：{vocab}")
    print(f"'train' 在集合中吗：{'train' in vocab}")   # in 对 set 是 O(1)

    batch1 = {"a", "b", "c"}
    batch2 = {"b", "c", "d"}
    print(f"交集：{batch1 & batch2}，并集：{batch1 | batch2}，差集：{batch1 - batch2}")

    # ---------- 切片：所有序列通用的子序列语法 ----------
    epochs = list(range(10))        # [0..9]
    print(f"前 3 个：{epochs[:3]}")
    print(f"后 3 个：{epochs[-3:]}")
    print(f"隔一个取一个：{epochs[::2]}")
    print(f"反转：{epochs[::-1]}")  # 步长 -1 即反转，也适用于字符串

    # ---------- 推导式：一行完成「筛选 + 变换」 ----------
    values = [3, -1, 4, -1, 5, -9, 2, 6]
    squares = [v * v for v in values]                 # map
    positives = [v for v in values if v > 0]          # filter
    pos_squares = [v * v for v in values if v > 0]    # filter + map
    print(f"平方：{squares}")
    print(f"正数：{positives}")
    print(f"正数的平方：{pos_squares}")

    # dict 推导式：给每个指标名生成一份假的历史记录
    history = {name: [float(i) for i in range(3)] for name in ["loss", "acc"]}
    print(f"history = {history}")

    # 推导式 vs 普通 for 循环（等价，但推导式更短、意图更清晰）
    result = []
    for v in values:
        if v > 0:
            result.append(v * v)
    assert result == pos_squares    # assert：条件为假时抛 AssertionError，常用于自检
    print("推导式与 for 循环结果一致")


if __name__ == "__main__":
    main()
```

## 练习

1. 统计一段英文 text 中每个单词出现的次数，返回 dict。提示：`text.split()` 后 `d[w] = d.get(w, 0) + 1`。
2. 一行推导式：把 `[5, 2, 9, 1, 7]` 中偶数翻倍、奇数清零。提示：条件表达式 `v*2 if v % 2 == 0 else 0` 放在 for 之前。
3. 写函数 `is_palindrome(s)`，只比较小写字母、忽略其他字符。提示：先用推导式过滤出字母并 lower，再与 `[::-1]` 比较。
4. 两轮训练各自的样本 id 集合为 s1、s2，求两轮都出现的 id 与只在一轮出现的 id。提示：交集 `&`，对称差 `^`。

## 小结与自测

1. list 与 tuple 怎么选？—— 要变用 list；固定结构、作 dict 键、多返回值用 tuple。
2. `d[k]` 与 `d.get(k)` 的区别？—— 前者键不存在抛 KeyError，后者返回 None 或给定默认值。
3. `xs[1:4]` 取到哪些下标？—— 1、2、3，含头不含尾。
4. 推导式的固定语序？—— `[表达式 for 变量 in 序列 if 条件]`，先筛后算。
5. 为什么 `in` 对 set 快而对 list 慢？—— set 是哈希表 O(1)，list 是线性扫描 O(n)。
6. 切片 `xs[::-1]` 是什么？—— 反转副本，原序列不变。
