# 第 4 课：函数与函数式特性

> 🎬 开场钩子：一个函数被连续调用两次，没有全局变量、没有任何存储，第一次返回 `['a']`，第二次却返回 `['a', 'b']`——它好像「记住」了上一次调用。这不是灵异事件，是 Python 最著名的默认值陷阱；本课结束时，你能在面试官面前当场拆穿它。

⏱ 建议学时：1.5 小时

## 本课目标

1. 会定义带类型提示的函数，理解「没有方法重载」带来的写法变化
2. 熟练使用关键字参数调用，能读出 `*args` / `**kwargs` 的收集与转发行为
3. 牢记可变默认值陷阱，并写出正确版本
4. 会用 `lambda` + `sorted(key=)`，知道 map/filter 与推导式的取舍
5. 理解「函数是一等公民」：函数可存变量、当参数、当返回值（读懂 ML 训练代码的关键）

完整可运行示例见 `code/L04_functions_demo.py`。

## 4.1 def 与类型提示

```python
def train(epochs: int, lr: float = 1e-3, verbose: bool = False) -> None:
    """类型提示写法：参数名: 类型 = 默认值，-> 后是返回类型。"""
    ...
```

要点：

- 函数是顶层公民，**不需要包在类里**（Java 的「一切皆类」不成立）
- **没有方法重载**：同名 `def` 后者直接覆盖前者。Java 里靠重载实现的「多种调用形态」，Python 靠默认参数 + 可变参数实现
- 类型提示（type hints）**运行时不强制**，是给 IDE、静态检查器和读代码的人看的。团队代码与 ML 开源项目都写，建议养成习惯
- 文档字符串（docstring）：函数体第一行的 `"""..."""`，相当于 Javadoc

> ☕ Java 视角：类型提示 ≈ 把 Javadoc 的参数说明标准化成了语法。没有重载是最大的心智切换：看到同名函数别以为有多个版本，只有一个，签名里带默认值。

## 4.2 参数的四种形态

```python
def connect(host, port=5432, *, timeout=10, pool_size=5):
    ...
```

1. **位置参数**：`connect("db.local")`，按顺序
2. **关键字参数**：`connect("db.local", timeout=30)`——调用时写参数名。这是 Python 杀手级特性，参数多时调用处自解释，ML 库 API 全是这种风格：`model.fit(X, y, epochs=10, verbose=0)`
3. **默认值**：定义时 `port=5432`，不传就用默认
4. **`*args` / `**kwargs`**：收集多余的参数

```python
def flexible_report(title, *columns, **options):
    # *columns 把多余的位置参数打包成 tuple
    # **options 把多余的关键字参数打包成 dict
    print(columns, options)

flexible_report("训练报告", "loss", "acc", lr=0.001, epochs=10)
# ('loss', 'acc') {'lr': 0.001, 'epochs': 10}
```

反向用法是**解包转发**：`f(*args_list, **kwargs_dict)` 把收集的参数原样传给下一层——写装饰器、封装框架函数时的标准动作。

> ☕ Java 视角：Java 只有 `Object...` 可变参数且只能收位置参数，想要「关键字参数」得写 Builder 或多个重载。`*args/**kwargs` 一次解决了「参数不定长」和「调用可命名」两件事。你会在几乎每个 ML 框架的训练入口看到 `**kwargs` 一路向下转发。

## 4.3 经典陷阱：可变默认值

```python
def bad_append(item, bucket=[]):     # 错误！
    bucket.append(item)
    return bucket

bad_append("a")   # ['a']
bad_append("b")   # ['a', 'b']  ← 惊喜：上次的 'a' 还在！
```

原因：**默认值只在 def 执行时求值一次**，之后所有调用共享同一个 list 对象。这是 L02「可变对象 + 共享引用」的直接应用。

正确写法：

```python
def good_append(item, bucket=None):
    if bucket is None:
        bucket = []          # 每次调用新建
    bucket.append(item)
    return bucket
```

> ☕ Java 视角：Java 的默认参数不存在，所以没这个坑；等价直觉是「static 字段被所有实例共享」。面试级高频题，见到 `def f(x, acc=[])` 条件反射报警。第 5 课 dataclass 的 `field(default_factory=list)` 是同一问题的框架级答案。

## 4.4 lambda 与 sorted/map/filter

`lambda` 是「一行、匿名、单表达式」的小函数：

```python
square = lambda x: x * x        # 语法：lambda 参数: 表达式
```

主要舞台是**当 key 用**（复杂函数请老实 `def`）：

```python
models = [("cnn", 0.91), ("rnn", 0.87), ("transformer", 0.95)]

ranked = sorted(models, key=lambda m: m[1], reverse=True)   # 按准确率降序
# [('transformer', 0.95), ('cnn', 0.91), ('rnn', 0.87)]

sorted(words, key=len)            # 内置函数也能当 key
sorted(pairs, key=lambda p: (p[0], -p[1]))   # 多级排序：tuple 逐项比
```

`map` / `filter` 返回**迭代器**（惰性），`list()` 展开后等价于推导式：

```python
doubled = list(map(lambda v: v * 2, [1, 2, 3]))   # [2, 4, 6]
big = list(filter(lambda v: v > 0.4, losses))     # 筛选
```

社区习惯：简单变换优先推导式（可读性更好），`sorted(key=...)` 里的 lambda 无可替代。`functools` 里的 `reduce` 用得少，知道即可。

## 4.5 函数是一等公民

函数可以：存进变量、放进 list/dict、当参数传、当返回值 return。

```python
def mean(xs): return sum(xs) / len(xs)
def variance(xs):
    m = mean(xs)
    return sum((x - m) ** 2 for x in xs) / len(xs)

metrics = {"mean": mean, "var": variance}     # 函数放进 dict
print(metrics["mean"]([1.0, 2.0, 3.0]))       # 按名字取出并调用

def evaluate(xs, metric):                     # 函数当参数：策略模式既视感
    return metric(xs)

evaluate(losses, metric=variance)             # 「怎么评估」被注入进来
```

**闭包**：内层函数记住外层变量，可当「函数工厂」：

```python
def make_multiplier(factor):
    def multiply(x):
        return x * factor     # 捕获 factor
    return multiply

times3 = make_multiplier(3.0)
times3(10)    # 30.0
```

顺带认识**装饰器**语法（第 5 课 `@property`、后面深度学习代码里大量出现）：`@dec` 作用在函数上，本质就是 `func = dec(func)`——把函数传给另一个函数、拿回一个新函数。现在只需看懂这一句等价关系。

> ☕ Java 视角：Java 8 之后你用 `Function<T,R>`、`Consumer<T>` 和 lambda 表达式做这些事，需要函数式接口「认证」过才行。Python 的函数天然就是对象，没有任何接口门槛——这就是为什么 PyTorch 的损失函数、优化器、回调全都能像普通值一样传来传去。

**为什么 ML 代码全是「函数传函数」**：损失函数（换一个 loss 就换一种训练目标）、评估指标（accuracy/F1 各写一个函数按需传入）、回调（每个 epoch 结束干什么）、数据增强（对样本应用的变换函数）……本质都是「把行为参数化」。本课的 `evaluate(xs, metric=mean)` 就是这个模式的微缩版。

> 🍿 彩蛋｜@ 不是注解：Python 装饰器和 Java 注解长得像双胞胎，性格却相反——注解是被动的元数据标签，静静等着框架来读；装饰器是主动的函数变换，`@dec` 出现的那一刻就实打实执行了 `func = dec(func)`。以后在 ML 代码里见到 `@` 开头的东西，记住它不是注释，是当场给你换了一个新函数。

## 完整演示代码

与 `code/L04_functions_demo.py` 相同：

```python
"""L04：函数与函数式特性演示。运行：python3 code/L04_functions_demo.py"""
from typing import Callable


def evaluate(xs: list[float], metric: Callable[[list[float]], float]) -> float:
    """把「怎么评估」作为参数传进来——函数是一等公民。

    Callable[[list[float]], float] 表示：接收 list[float]、返回 float 的函数类型。
    """
    return metric(xs)


def mean(xs: list[float]) -> float:
    return sum(xs) / len(xs)


def variance(xs: list[float]) -> float:
    m = mean(xs)
    return sum((x - m) ** 2 for x in xs) / len(xs)   # 生成器表达式：不建中间列表


def flexible_report(title: str, *columns: str, **options: object) -> None:
    """*columns 收集多余位置参数为 tuple；**options 收集多余关键字参数为 dict。"""
    print(f"== {title} ==")
    print(f"列：{columns}")            # tuple
    print(f"选项：{options}")          # dict


def bad_append(item: str, bucket: list[str] = []) -> list[str]:
    # 陷阱演示：默认 list 只在函数定义时创建一次，所有调用共享同一个对象
    bucket.append(item)
    return bucket


def good_append(item: str, bucket: list[str] | None = None) -> list[str]:
    # 正确姿势：默认 None，函数体内新建
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


def make_multiplier(factor: float) -> Callable[[float], float]:
    """返回函数：闭包捕获了 factor——「工厂」生成行为。"""
    def multiply(x: float) -> float:
        return x * factor
    return multiply


def main() -> None:
    losses = [0.9, 0.6, 0.4, 0.35, 0.31]

    # 1. 把评估函数当参数传（关键字参数调用，自解释）
    print(f"mean = {evaluate(losses, metric=mean):.4f}")
    print(f"variance = {evaluate(losses, metric=variance):.6f}")

    # 2. lambda：一句话的小函数，最常作 sorted 的 key
    models = [("cnn", 0.91), ("rnn", 0.87), ("transformer", 0.95)]
    ranked = sorted(models, key=lambda m: m[1], reverse=True)   # 按准确率降序
    print(f"模型排行：{ranked}")

    # 3. map/filter：返回迭代器，list() 展开后等价于推导式
    doubled = list(map(lambda v: v * 2, [1, 2, 3]))
    big = list(filter(lambda v: v > 0.4, losses))
    print(f"map 结果：{doubled}；filter 结果：{big}")

    # 4. *args / **kwargs：参数的收集
    flexible_report("训练报告", "loss", "acc", lr=0.001, epochs=10)

    # 5. 可变默认值陷阱：连续调用 bad_append 会「记住」上一次的内容
    print(f"bad 第一次：{bad_append('a')}")
    print(f"bad 第二次：{bad_append('b')}")     # ['a', 'b'] —— 惊喜！
    print(f"good 第二次：{good_append('b')}")   # ['b'] —— 干净

    # 6. 闭包：函数工厂
    times3 = make_multiplier(3.0)
    print(f"times3(10) = {times3(10)}")


if __name__ == "__main__":
    main()
```

## 练习

1. 写 `apply_twice(f, x)` 返回 `f(f(x))`，用 `lambda v: v + 10` 验证。提示：函数当参数传，直接嵌套调用。
2. 把 `{"adam": 0.9, "sgd": 0.82, "adamw": 0.93}` 按 value 降序排成 `[(名字, 分数)]` 列表。提示：`d.items()` + `key=lambda kv: kv[1]`。
3. 写 `count_if(pred, xs)` 统计满足条件的元素个数，并统计 losses 中 `< 0.5` 的个数。提示：`sum(1 for x in xs if pred(x))`。
4. 在 REPL 里查看 `bad_append.__defaults__`，解释陷阱根源。提示：默认值元组挂在函数对象上、只求值一次。

## 小结与自测

1. 关键字参数解决了什么问题？—— 调用处自解释、参数多时不怕顺序错，可只传想改的。
2. `*args` / `**kwargs` 分别收集什么？—— 多余位置参数打包成 tuple / 多余关键字参数打包成 dict。
3. 可变默认值为什么危险？—— 默认对象在 def 时创建一次，被所有调用共享。
4. lambda 与 def 的取舍？—— 单表达式临时逻辑用 lambda（尤其 sorted 的 key），其余一律 def。
5. 「函数是一等公民」意味着什么？—— 函数与普通对象无异：可赋值、入容器、当参数、当返回值。
6. 装饰器 `@dec` 的本质？—— `func = dec(func)` 的语法糖：函数进、新函数出。
