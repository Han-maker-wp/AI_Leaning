## 5.1 最小类与 __init__：没有仪式感的 POJO

```python
class Dataset:
    kind = "tabular"                        # 类属性（类似 static，所有实例共享）

    def __init__(self, name, rows):         # 初始化方法，self 必须显式写
        self.name = name                    # 实例属性：直接赋值即「声明 + 赋值」
        self.rows = rows

ds = Dataset("iris", [[5.1, 3.5]])          # 注意：调用时不传 self
print(ds.name)                              # 属性直接公开访问，没有 getter/setter
```

要点：

- `__init__` 是初始化器（构造工作实际由 `__new__` 完成，知道即可）；`Dataset(...)` 会自动传入实例作为 self
- **字段不用预先声明**，`self.x = ...` 赋值即创建；惯例集中在 `__init__` 里
- 属性默认公开；名字前加下划线（`_x`）表示「内部使用」的君子协定

> ☕ Java 视角：self 就是 this，但必须写成方法的第一个参数——`ds.summary()` 等价于 `Dataset.summary(ds)`，这个视角能解释一切。没有 private/protected 关键字，只有下划线约定（`_name` 内部、`__name` 触发名称改写）。没有接口强制、没有抽象类语法糖（标准库有 `abc` 模块，用到再学）。

> 🍿 彩蛋｜没有警察，只有君子：Python 没有 private/protected 关键字，封装靠下划线约定——`_name` 意思是「内部使用，请勿乱碰」，但语言不拦你，纯属「我信任你」的君子协定。Java 老兵初到会不适应：这里没有编译器警察站岗，全靠社区公德。

## 5.2 实例属性 vs 类属性

```python
class Dataset:
    kind = "tabular"            # 类属性：定义在类体、方法外

ds1 = Dataset(...)
ds1.kind          # 'tabular'：实例上找不到时回落到类属性
ds1.kind = "img"  # 这是在 ds1 上创建实例属性，遮住类属性，不影响其他实例
Dataset.kind = "seq"   # 改类属性，影响所有「未被遮住」的实例
```

> ☕ Java 视角：类属性 = static 字段，实例属性 = 成员字段。区别是 Python 查找顺序：实例 dict → 类 dict → 父类链（MRO），同名时会「遮蔽」而不是报错——小心别误改共享状态，ML 代码里常见的坑是把可变对象挂成类属性。

## 5.3 继承与 super()

```python
class LabeledDataset(Dataset):              # 括号里是父类，支持多继承（少用）
    def __init__(self, name, rows, labels):
        super().__init__(name, rows)        # 复用父类初始化
        self.labels = labels

    def summary(self):
        return f"{self.name}: {len(self)} 条，标签 {len(self.labels)} 个"
```

> ☕ Java 视角：`super().__init__(...)` ≈ `super(name, rows)`，且同样建议「先跑父类初始化再干自己的事」。`isinstance(obj, Cls)` ≈ `instanceof`；`issubclass(A, B)` 判断继承关系。方法重写无需 @Override，直接同名 def 即覆盖。

## 5.4 魔术方法：让对象长进语言里

双下划线包住的方法是 Python 的「运算符协议」。实现它们，你的对象就能用原生语法操作：

| 魔术方法 | 换来的能力 | ML 场景 |
|---|---|---|
| `__repr__` | `print(obj)` / 调试时的显示 | 打印模型、配置 |
| `__str__` | `str(obj)` 用户友好显示（缺省回落到 `__repr__`） | 同上 |
| `__len__` | `len(obj)` | 数据集大小 `len(dataset)` |
| `__getitem__` | `obj[i]`、切片、for 遍历 | `dataset[0]` 取样本 |
| `__call__` | `obj(x)`——实例可调用 | **`model(x)` 前向传播** |
| `__eq__` | `==` 值比较 | dataclass 自动生成 |
| `__add__` 等 | `+` `-` `*` 运算符 | 自己实现向量/矩阵类 |

```python
class Dataset:
    def __len__(self):
        return len(self.rows)

    def __getitem__(self, i):
        return self.rows[i]

ds = Dataset("iris", [[5.1], [4.9]])
len(ds)        # 2
ds[0]          # [5.1]
for row in ds: ...    # for 循环也走 __getitem__
```

`__repr__` 惯例：无歧义、尽量能还原对象的信息（`Dataset(name='iris', n=150)`）；调试价值远超默认的 `<__main__.Dataset object at 0x...>`。**每个你写的类都值得配一个 `__repr__`**。

`__call__` 单独强调：`model(x)` 这种「像函数一样调实例」的写法，就是 PyTorch 里 `net(input)` 的原理——`nn.Module` 实现了 `__call__`，内部（先跑钩子再）转给 `forward`。

> ☕ Java 视角：Java 没有运算符重载，等价能力得靠 `Comparable`/`equals`/函数式接口。Python 的思路是「协议」：实现约定名字的方法，语言语法就认可你——这些方法名就是隐式接口。

> 🍿 彩蛋｜行话 dunder：双下划线包住的魔术方法，圈子里读作 dunder——double underscore 的缩读，`__init__` 念「dunder-init」。日后听人聊「dunder method」别懵，指的就是本节这套协议方法。

## 5.5 鸭子类型：没有接口的多态

> 「走起来像鸭子、叫起来像鸭子，那它就是鸭子。」

```python
def describe(obj):
    return obj.summary() if hasattr(obj, "summary") else repr(obj)
```

不检查类型，只管对象**有没有这个方法**。有就走，没有就 `AttributeError`（或先 `hasattr` 探测、或 try/except 兜底——社区称之为 EAFP：先斩后奏式编程）。

> ☕ Java 视角：Java 的多态靠接口编译期锁契约：不实现 Comparable 就不能传给 sort。Python 把契约检查推迟到运行时：任何有 `summary()` 的对象都能传进 `describe`。好处是极度灵活（第三方类不用改源码就能适配你的函数），代价是错误暴露晚。静态检查工具配合 `typing.Protocol`（协议结构化类型）可以补回编译期检查，读开源代码时见到再查。

你已经在用鸭子类型了：`print()` 接受任何有 `__repr__`/`__str__` 的对象，`sorted(key=...)` 接受任何可调用对象——没有谁声明过接口。

## 5.6 @dataclass 与 @property

**@dataclass：一行顶一屏 POJO 样板**

```python
from dataclasses import dataclass, field

@dataclass
class TrainConfig:
    lr: float = 1e-3                       # 字段名: 类型 = 默认值
    epochs: int = 10
    tags: list[str] = field(default_factory=list)   # 可变默认值必须用 default_factory
```

自动生成 `__init__`、`__repr__`、`__eq__`。

> ☕ Java 视角：等价于 Lombok 的 @Data 或 Java record，把 constructor/equals/hashCode/toString 的样板全省了。与 record 的差异：dataclass 默认**可变**（record 不可变），要不可变加 `frozen=True`。而 `field(default_factory=list)` 正是第 4 课「可变默认值陷阱」的框架级解法——每次创建实例时现调 factory。

**@property：把方法伪装成属性**

```python
class TrainConfig:
    @property
    def total_steps_hint(self) -> int:     # 读取时 cfg.total_steps_hint，不加括号
        return self.epochs * 100
```

价值：一开始直接暴露属性，之后需要计算/校验时升级成 property，**调用方代码一行不改**——Java 里「字段升级为 getter」要改所有调用点，Python 靠这个机制鼓励「先公开，后封装」。

## 5.7 伏笔：PyTorch 的 nn.Module 长什么样

提前看一眼简化骨架（真实 PyTorch 更复杂，结构一致）：模型 = 继承 + 属性挂子模块 + forward 定义计算：

```python
import torch.nn as nn

class MyNet(nn.Module):                 # 真实 PyTorch 写法（预告，只需看结构）
    def __init__(self):
        super().__init__()              # nn.Module 的初始化注册参数容器
        self.fc = nn.Linear(4, 3)       # 一层全连接，本质 y = Wx + b

    def forward(self, x):
        return self.fc(x)

net = MyNet()
out = net(x)     # 实例可调用：nn.Module 的 __call__ → forward(x)
```

现在你能逐行解释它了：继承与 `super().__init__()`（本课 5.3）、`self.fc` 实例属性（5.1）、`net(x)` 走 `__call__`（5.4）。第 2 阶段见。

## 完整演示代码

与 `code/L05_class_demo.py` 相同：

```python
"""L05：类与对象演示。运行：python3 code/L05_class_demo.py"""
from dataclasses import dataclass, field


class Dataset:
    """最简类：数据 + 行为放一起。类属性 kind 被所有实例共享（类似 Java static）。"""

    kind = "tabular"                        # 类属性（static）

    def __init__(self, name: str, rows: list[list[float]]) -> None:
        # self 显式出现在每个方法的第一个参数——它就是 Java 的 this
        self.name = name                    # 实例属性，每个对象各自一份
        self.rows = rows

    def __len__(self) -> int:               # 让 len(ds) 可用
        return len(self.rows)

    def __getitem__(self, i: int):          # 让 ds[0]、for 循环可用
        return self.rows[i]

    def __repr__(self) -> str:              # 面向开发者的表示，打印/调试时看到
        return f"Dataset(name={self.name!r}, n={len(self.rows)})"


class LabeledDataset(Dataset):              # 继承：括号里写父类
    def __init__(self, name: str, rows, labels: list[int]) -> None:
        super().__init__(name, rows)        # 复用父类初始化
        self.labels = labels

    def summary(self) -> str:
        counts: dict[int, int] = {}
        for y in self.labels:
            counts[y] = counts.get(y, 0) + 1
        return f"{self.name}: {len(self)} 条，类别分布 {counts}"


@dataclass
class TrainConfig:
    """dataclass：自动生成 __init__/__repr__/__eq__，相当于 Java record。

    可变默认值必须用 field(default_factory=...)，原理同 L04 的可变默认值陷阱。
    """
    lr: float = 1e-3
    epochs: int = 10
    tags: list[str] = field(default_factory=list)

    @property
    def total_steps_hint(self) -> int:
        """property：像访问属性一样调用计算逻辑（无括号）。"""
        return self.epochs * 100


class FakeModule:
    """简化版 nn.Module 骨架：体会「模型是类、层是属性、调用走 forward」。"""

    def __init__(self, in_dim: int, out_dim: int) -> None:
        # 假装这两个 list 是可训练参数（真正的权重是 numpy 数组/tensor）
        self.weight = [[0.01] * in_dim for _ in range(out_dim)]
        self.bias = [0.0] * out_dim
        self.training = True

    def forward(self, x: list[float]) -> list[float]:
        out = []
        for row, b in zip(self.weight, self.bias):
            out.append(sum(wi * xi for wi, xi in zip(row, x)) + b)
        return out

    def __call__(self, x: list[float]) -> list[float]:
        # model(x) 之所以能调用，是因为实例实现了 __call__
        return self.forward(x)


def describe(obj) -> str:
    """鸭子类型：不检查类型，只管对象「有没有这个能力」。"""
    return obj.summary() if hasattr(obj, "summary") else repr(obj)


def main() -> None:
    ds = LabeledDataset("iris-mini", [[5.1, 3.5], [4.9, 3.0]], [0, 1])
    print(ds)                       # 触发 __repr__
    print(len(ds), ds[0])           # 触发 __len__ 与 __getitem__
    print(ds.summary())

    print(Dataset.kind, ds.kind)    # 类属性通过类或实例都能读

    cfg = TrainConfig(lr=0.01)
    cfg.tags.append("baseline")
    print(cfg)                      # dataclass 自动生成的 repr
    print(f"total_steps_hint = {cfg.total_steps_hint}")   # property 不加括号

    model = FakeModule(in_dim=2, out_dim=3)
    logits = model([5.1, 3.5])      # 等价于 model.forward(...)——__call__ 的功劳
    print(f"logits = {[round(v, 4) for v in logits]}")

    print(describe(ds))             # 有 summary → 调用（鸭子类型）
    print(describe(cfg))            # 没有 summary → 回退到 repr


if __name__ == "__main__":
    main()
```

## 练习

1. 给 Dataset 实现 `__eq__`：name 与 rows 都相等才相等。提示：先 `isinstance(other, Dataset)` 防类型错误，再逐字段比。
2. 写类 Vec2D：支持 `v1 + v2`（`__add__`）与范数 `abs(v)`（`__abs__`）。提示：魔术方法返回新 Vec2D，范数用 `(x**2 + y**2) ** 0.5`。
3. 用 @dataclass 定义 `ModelCheckpoint(step, loss, path)`，创建两个实例打印并比较。提示：观察自动生成的 `__repr__` 与 `__eq__`。
4. 给 TrainConfig 加 property `is_fine_tuning`：lr < 1e-4 时为 True。提示：@property 装饰一个返回 bool 的方法。

## 小结与自测

1. self 是什么？—— 方法的第一个参数，调用时自动传入实例，等价 this 但必须显式写。
2. 类属性与实例属性的区别？—— 类属性类似 static 全体共享；实例属性各自独立，查找时实例优先、遮蔽类属性。
3. `__repr__` 与 `__str__` 谁先被 print 使用？—— `__str__`，没实现则回落到 `__repr__`；调试场景优先实现 `__repr__`。
4. 鸭子类型与 Java 接口的本质区别？—— 编译期契约 vs 运行期「有方法就行」，灵活但错误暴露晚。
5. `model(x)` 为什么能像函数一样调用？—— 实例实现了 `__call__`，PyTorch 的 nn.Module 正是这样转发到 forward。
6. @dataclass 替你生成了什么？—— `__init__`、`__repr__`、`__eq__`（可选更多），相当于 Java record / Lombok @Data。
