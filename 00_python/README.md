# 阶段 0：Python 速成（面向 Java 开发者）

> 面向的你：多年 Java Web 开发经验、数学扎实、Python 零基础。
> 目标不是「再学一门语言」，而是 4 个月后能独立微调大模型——Python 是那条路上每天都要用的笔。

## 阶段目标：1 周达到「能写」

「能写」的验收口径：

- 不看语法手册，独立完成一个命令行待办事项工具（见文末验收标准）
- 读懂任意一段常规 ML 示例代码（含 NumPy 向量化写法）
- 会用 uv 管理虚拟环境与依赖，能看懂 pyproject.toml

## 学习方式约定

- 每课讲义自带完整可运行示例；`code/` 目录里有对应的独立 .py 文件，逐个跑一遍，并刻意改坏一处（改形状、改参数）观察报错
- 遇到 Java 没有的概念，讲义会用 `> ☕ Java 视角：...` 引用块专门解释
- 你数学很好，讲义里的公式不会从零讲，重点放在「公式 ↔ 代码」的映射上

## 验收标准：命令行待办事项工具

不借助 AI 生成整段代码（可以查官方文档），独立完成：

1. 程序 `todo.py`，启动后进入交互循环，支持命令：
   - `add 买牛奶` —— 添加一条待办
   - `list` —— 列出全部待办（带序号与完成状态）
   - `done 2` —— 把第 2 条标记为完成
   - `remove 2` —— 删除第 2 条
   - `quit` —— 退出并把数据保存到 `todos.json`，下次启动自动加载
2. 强制要求用到：list/dict 数据结构、至少一个函数、至少一个类、json 标准库、异常处理（文件不存在时的兜底）
3. 预计代码量 80~120 行。写完后再翻回第 2~6 课讲义，把当初模糊的点标记重学

通过验收的标志：程序连续两天可正常使用，且你能向别人解释代码里每一行为什么这么写。
