## 2.1 模型假设：y = wx + b

最简单的「从特征猜数值」模型——用一条直线拟合数据：

```
标量式：  ŷ = w·x + b            （x 是单个特征）
向量式：  ŷ = wᵀx + b            （x ∈ R^d，w ∈ R^d）
批量式：  ŷ = Xw + b             （X ∈ R^{n×d}，一次算 n 个样本）
```

w 是**权重**（每维特征的重要性），b 是**偏置**（截距）。「训练线性回归」就是找让预测最准的那组 (w, b)——参数就这两个（多维时 d+1 个），是所有模型里最寒酸的，但结构（参数化函数 + 数据打分）与大模型完全同构。

> ☕ Java 视角：把 `ŷ = Xw + b` 想成一个矩阵乘法服务：输入一批样本 `(n,d)`，配一组权重 `(d,)`，吐出一列预测 `(n,)`——阶段 0 第 7 课的形状流转原样复用。以后见到神经网络，先找它的 `X @ W + b`，都长这样。

## 2.2 损失函数：为什么是「平方和」

损失函数把「预测有多差」压缩成一个数。回归任务的标准选择是均方误差 MSE：

```
L(w, b) = (1/n) Σᵢ (ŷᵢ − yᵢ)²
```

直觉：每个样本的误差（残差）平方后求平均。预测偏 1 罚 1，偏 2 罚 4，偏 3 罚 9——**大错误被超线性地重罚**。

为什么是平方而不是绝对值（三个理由，第三个你一看便知）：

1. **处处可导**：|·| 在 0 点不可导，平方是光滑函数——对下一课的梯度下降至关重要
2. **惩罚结构合理**：对离群的大误差更狠，多数场景符合预期（代价是对离群点敏感）
3. **概率视角**：若假设噪声 ε ~ N(0, σ²)，则最小化 MSE 等价于高斯噪声下的最大似然估计。一句话：**在高斯世界里，平方损失不是拍脑袋，是推出来的**

> 🍿 彩蛋｜优先权之争：最小二乘法牵扯着两位大数学家——勒让德率先刊出，高斯 1809 年也发表了它并坚称自己用得更早，两人为「谁先发明」闹得不太愉快。两百多年后，这场公案的主角换成了你手上的 `mse_loss`：同一种「平方和最小」的思想，从天文定轨一路用到了大模型训练。

## 2.3 损失是参数的函数：碗状曲面

关键视角转换（ML 的「任督二脉」之一）：

- 训练时，**数据 (X, y) 是固定的常量**
- 真正的自变量是**参数 (w, b)**
- 每取一组 (w, b)，就有一条直线、一个 MSE 值 → L 是定义在参数空间上的函数

对线性回归 + MSE：L 是关于 (w, b) 的**二次函数**。二维参数时它是开口向上的抛物面（三维碗），等高线是一圈圈同心椭圆。你的线代直觉可以直接上线：这是正定二次型 `L ∝ wᵀAw − 2bᵀw + c`，A 正定 → 唯一全局最小值。

**训练 = 在这个碗面上找最低点。**下一课的梯度下降是「怎么走下坡」，本课先把「碗长什么样」焊进脑子。

## 2.4 动手：生成数据 → 手写 MSE → 闭式解 → 画拟合线

完整代码（与 `code/L02_linear_regression.py` 相同）：

```python
"""L02：线性回归——生成数据、手写 MSE、闭式解与拟合线可视化。

运行前：uv pip install numpy matplotlib
"""
import numpy as np
import matplotlib.pyplot as plt


def mse_loss(y_pred: np.ndarray, y: np.ndarray) -> float:
    """均方误差 MSE = (1/n) * Σ (ŷ - y)^2。

    (y_pred - y) 是形状 (n,) 的残差向量，与自身点积即平方和——向量化写法。
    """
    n = y.shape[0]
    return float((y_pred - y) @ (y_pred - y) / n)


def add_bias(X: np.ndarray) -> np.ndarray:
    """给 X 左侧拼一列 1，把 b 吸收进 w（x0 恒为 1）。X: (n,d) → (n,d+1)"""
    n = X.shape[0]
    return np.hstack([X, np.ones((n, 1))])


def main() -> None:
    # 1. 造「真实规律 + 噪声」的数据：y = 2x + 1 + ε，ε ~ N(0, 0.8²)
    rng = np.random.default_rng(0)
    n = 120
    X = rng.uniform(0, 5, size=(n, 1))              # (n,1)：保持二维，习惯 batch 维
    y = 2.0 * X[:, 0] + 1.0 + rng.normal(0, 0.8, size=n)

    # 2. 用「随手猜」的参数算损失，亲眼看到损失随参数变化（b 固定 1.0 只看 w）
    for w_try in [0.0, 1.0, 2.0, 3.0]:
        y_hat = w_try * X[:, 0] + 1.0
        print(f"w = {w_try:.1f} → MSE = {mse_loss(y_hat, y):.4f}")

    # 3. 闭式解（正规方程）：w* = (XᵀX)^{-1} Xᵀ y，d 很小时毫秒级出结果
    Xb = add_bias(X)                                 # (n,2)，b 并入 w
    w_closed = np.linalg.inv(Xb.T @ Xb) @ Xb.T @ y   # 求得 [w, b]
    print(f"闭式解：w = {w_closed[0]:.4f}, b = {w_closed[1]:.4f}")
    print(f"闭式解的 MSE = {mse_loss(Xb @ w_closed, y):.4f}")

    # 4. 可视化：散点 + 拟合线
    plt.figure(figsize=(6, 4))
    plt.scatter(X[:, 0], y, s=15, alpha=0.6, label="data")
    xs = np.linspace(0, 5, 50)
    plt.plot(xs, w_closed[0] * xs + w_closed[1], "r-", lw=2, label="closed-form fit")
    plt.xlabel("x")
    plt.ylabel("y")
    plt.title("Linear regression fit")
    plt.legend()
    plt.savefig("L02_fit.png", dpi=150)
    plt.show()
    print("拟合线图已保存为 L02_fit.png")


if __name__ == "__main__":
    main()
```

三处值得停下咀嚼：

1. **`mse_loss` 只有两行**：残差向量与自身点积。用你的线代话说，平方和 = 残差向量的范数平方 `‖e‖² = eᵀe`。没有循环，没有索引——这就是阶段 0 第 7 课的兑现
2. **`add_bias` 的意义**：把 b 吸收进 w（在 X 左侧加全 1 列），公式统一成 `ŷ = Xw`。矩阵求逆、梯度推导都因此干净一格。深度学习框架里 bias 单独存在，两种写法都要认得
3. **步骤 2 的循环**是「损失是参数的函数」的具象演示：数据不动，w 从 0 走到 3，MSE 先降后升——你已经在一维切面上摸到了碗

## 2.5 闭式解：知道存在即可

对 MSE + 线性模型，令梯度为零可解出解析解（正规方程）：

```
w* = (XᵀX)⁻¹ Xᵀ y
```

它存在、精确、一步到位。那为什么还要学梯度下降（下一课）？三个原因：

1. **算不动**：求逆是 O(d³)。d 上万就够呛；LLM 的 d 是百亿级
2. **推不出**：一旦模型非线性（神经网络），损失不再有闭式解，「令梯度为零」变成解不出的高维非线性方程组
3. **梯度下降可扩展**：小批量、随机化、GPU 并行——它反而成了唯一实用的选择

所以闭式解在本阶段的角色：**给你一个「标准答案」用来验证梯度下降写对了没有**（练习 4 会用上）。

## 练习

1. 把噪声标准差从 0.8 调到 3.0，重跑观察拟合线与 MSE 的变化。提示：噪声越大，参数估计越不稳，拟合线随种子明显摆动。
2. 纸上画：固定 b=1.0，画出 L(w) 关于 w 的大致曲线（数据来自本课代码）。提示：开口向上的抛物线，最低点在 w≈2 附近。
3. 故意给 `mse_loss` 传入 `(n,1)` 与 `(n,)` 两个形状，观察结果。提示：(n,1)−(n,) 广播成 (n,n)——结果数值巨大但**不报错**，这类静默 bug 要靠看 shape 预防。
4. 数据生成改成 `y = −x + 3 + ε`，验证闭式解能还原参数。提示：只改一行，看 w_closed 是否 ≈ [−1, 3]。

## 小结与自测

1. 为什么选平方误差而不是绝对值？—— 处处可导、超线性惩罚大误差、高斯噪声下等价最大似然。
2. 「损失是参数的函数」怎么理解？—— 数据固定为常量，自变量是 (w,b)；优化对象是参数不是数据。
3. 线性回归的损失面什么形状？—— 凸抛物面（正定二次型），等高线为同心椭圆，有唯一全局最小。
4. 闭式解为什么在深度学习里不可用？—— O(d³) 算不动；非线性模型无闭式解可推。
5. add_bias 在做什么？—— 给 X 拼全 1 列，把 b 并入 w，统一成 ŷ=Xw 便于推导与计算。
