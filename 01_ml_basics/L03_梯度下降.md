# 第 3 课：梯度下降

> 🎬 开场钩子：1847 年，数学家柯西提出一个朴素的下山策略：大雾封山看不见谷底时，每一步只摸脚边最陡的下坡方向走。170 年后，这个策略换了个名字——梯度下降——成了训练从手机输入法到 ChatGPT 的所有 AI 的标准动作。今天你亲手实现它。

## 3.1 从导数到梯度：多元版的「坡度」

一元函数 y = f(x)：导数 f'(x₀) 是 x₀ 处的斜率——往右走一小步，函数值大约变化 f'(x₀)·δ。斜率为正说明右边更高。

多元函数 L(w, b)：每个参数各有一个偏导数 ∂L/∂w、∂L/∂b。把它们排成向量，就是**梯度**：

```
∇L = (∂L/∂w, ∂L/∂b)
```

用你的微积分直觉直接迁移：**梯度方向是当前点最陡的上升方向**（方向导数最大的方向）。于是「最快下山」就是它的反方向——负梯度。这就是算法的全部野心：每次都朝当前最陡的下坡方向挪一小步。

对线性回归 MSE，把 ŷᵢ = w·xᵢ + b 代入 L 求偏导（两行链式法则，你 30 秒能验算）：

```
∂L/∂w = (2/n) Σᵢ (ŷᵢ − yᵢ) · xᵢ     ← 误差 × 特征
∂L/∂b = (2/n) Σᵢ (ŷᵢ − yᵢ)          ← 误差
```

向量化写法（下一节的代码）：`grad_w = 2/n · Xᵀ(ŷ − y)`，`grad_b = 2/n · Σ(ŷ − y)`。

## 3.2 更新公式与学习率

```
w ← w − η · ∂L/∂w          （η 读作 eta，即 learning rate，代码里叫 lr）
b ← b − η · ∂L/∂b
```

一句话：**算出梯度，朝反方向走 lr 那么多，重复**。模型好坏的「评分」(loss) 与「改进动作」(梯度) 分离，训练循环因此可以被写成通用框架——PyTorch 的 `optimizer.step()` 三个单词干的就是这件事。

学习率 η 是最重要的超参数，它决定步子大小：

```
lr 合适:  loss 0.900 → 0.450 → 0.220 → 0.105 → 0.052 → ...   稳定收敛
lr 过小:  loss 0.900 → 0.899 → 0.898 → 0.897 → ...          龟速，epochs 内到不了谷底
lr 过大:  loss 0.900 → 1.400 → 0.200 → 2.100 → 9.87 → ...   来回跨越谷底，甚至发散
```

- **过小**：下降方向对，但步子太碎。曲线「缓慢地降」，浪费算力
- **过大**：一步跨过谷底到对面更高的坡上，越荡越高。曲线「震荡、爆炸」，甚至溢出成 nan
- **合适**：前快后稳地下降。实践中 0.001~0.1 之间试起，看 loss 曲线调

> 🍿 彩蛋｜「nan 了」是什么黑话：深度学习圈日常对话里，「loss nan 了」= 训练炸了。数值一旦溢出成 NaN（Not a Number），它会像传染病一样沿计算扩散——再怎么加减乘除都还是 NaN。本课 lr 过大的发散实验，就是你第一次亲手「炼」出 nan；以后跑大模型见到它，第一嫌疑人永远是学习率。

## 3.3 凸性：为什么线性回归不怕「局部最小」

第 2 课已确认：MSE + 线性模型的损失面是凸碗。凸函数没有「坑洼」——任何局部最小都是全局最小，梯度下降只要 lr 不离谱，必然滚向谷底。

但要提前打预防针：**神经网络是非凸的**，损失面上有大量鞍点与局部最小。神奇的是实践中 SGD 照样工作得很好（噪声帮助跳出鞍点），理论至今没有完全闭环——这是第 2 阶段的实验话题。本课你只需确信：在线性回归上，梯度下降收敛到的解 = 闭式解（练习 4 验证）。

## 3.4 批量 / 随机 / 小批量

上面公式里的 Σ 是对**全部 n 个样本**求和——每走一步都用完整训练集，叫**批量梯度下降（BGD）**。变体：

| 变体 | 每步用多少样本 | 梯度质量 | 速度/其他 |
|---|---|---|---|
| 批量 BGD | 全部 n 个 | 精确、稳定 | 一步很贵；大数据走不动 |
| 随机 SGD | 1 个 | 噪声极大 | 一步极快；抖动大但能抖出坏点 |
| 小批量 mini-batch | 32~512 个 | 折中 | **主流**：矩阵运算吃满 GPU 并行 |

mini-batch 是深度学习的事实标准：一批样本叠成 `(batch_size, d)` 的矩阵做一次 `X @ w`——**「批」不是工程妥协，是把随机性变成可调参数、同时吃满阶段 0 第 7 课矩阵化红利的 Sweet spot**。第 2 阶段的 DataLoader 就是在替你切批。

## 3.5 完整训练循环（必须亲手敲）

与 `code/L03_gradient_descent.py` 相同：

```python
"""L03：纯 numpy 手写梯度下降训练线性回归——未来所有训练循环的骨架。

运行前：uv pip install numpy matplotlib
"""
import numpy as np
import matplotlib.pyplot as plt


def main() -> None:
    # ========== 第 0 步：准备数据 y = 2x + 1 + 噪声 ==========
    rng = np.random.default_rng(0)
    n = 200
    X = rng.uniform(0, 5, size=(n, 1))                      # (n,1)
    y = 2.0 * X[:, 0] + 1.0 + rng.normal(0, 0.6, size=n)    # (n,)

    # ========== 第 1 步：初始化参数（一切从这里开始） ==========
    w = np.zeros(1)          # 也可以随机小值
    b = np.zeros(1)
    lr = 0.05                # 学习率 η
    epochs = 100             # 轮数

    history = []             # 记录每轮 loss，用于画下降曲线

    # ========== 第 2 步：训练循环（背下这个结构！） ==========
    for epoch in range(1, epochs + 1):
        # --- 前向传播：用当前参数算预测 ---
        y_pred = X[:, 0] * w[0] + b[0]                      # (n,)

        # --- 计算损失（监控训练进度用） ---
        loss = float(np.mean((y_pred - y) ** 2))

        # --- 反向传播：手写解析梯度 ---
        error = y_pred - y                                  # (n,) 残差
        grad_w = 2.0 * np.mean(error * X[:, 0])             # ∂L/∂w
        grad_b = 2.0 * np.mean(error)                       # ∂L/∂b

        # --- 参数更新：沿负梯度走一小步 ---
        w[0] -= lr * grad_w
        b[0] -= lr * grad_b

        history.append(loss)
        if epoch % 10 == 0 or epoch == 1:
            print(f"epoch {epoch:3d} | loss = {loss:.4f} | "
                  f"w = {w[0]:.4f}, b = {b[0]:.4f}")

    print(f"\n训练结果：w = {w[0]:.4f}, b = {b[0]:.4f}（真值 2.0 与 1.0）")

    # ========== 第 3 步：画 loss 下降曲线 ==========
    plt.figure(figsize=(6, 4))
    plt.plot(range(1, epochs + 1), history)
    plt.xlabel("epoch")
    plt.ylabel("MSE loss")
    plt.title("Gradient descent on linear regression")
    plt.grid(True)
    plt.savefig("L03_loss_curve.png", dpi=150)
    plt.show()
    print("loss 曲线已保存为 L03_loss_curve.png")


if __name__ == "__main__":
    main()
```

## 3.6 这个循环就是 PyTorch 训练循环的骨架

把本课循环与第 2 阶段将写的 PyTorch 循环逐行对上——**结构一模一样，只是三件事被框架接管**：

| 本课手写 | PyTorch 里的对应 | 变化 |
|---|---|---|
| `y_pred = X·w + b` | `y_pred = model(X)` | 前向计算包进类（阶段 0 L05 的 nn.Module 骨架） |
| `grad_w/grad_b` 两行解析梯度 | `loss.backward()` | **自动微分**：任意复杂计算图自动求梯度 |
| `w -= lr * grad_w` | `optimizer.step()` | 优化器对象管理参数更新（还有 Adam 等升级版） |
| `history.append(loss)` | 日志 / TensorBoard / tqdm | 不变 |
| `for epoch: ...` 外层循环 | 一字不改 | 不变 |

所以本课的练习价值极高：**你以后调试 LLM 微调脚本时，「loss 为什么不降」的诊断能力就来自亲手写过这个循环**。

## 小结与自测

1. 梯度的几何意义？—— 当前点最陡上升方向；负梯度即最陡下降方向。
2. lr 过大/过小的症状？—— 过大来回震荡甚至发散；过小收敛极慢、epochs 内到不了谷底。
3. 线性回归为什么不怕局部最小？—— MSE 对参数是凸函数，局部最小即全局最小。
4. mini-batch 为什么成为主流？—— 梯度质量与计算成本折中，批量矩阵运算吃满 GPU 并行。
5. PyTorch 的 backward() 替代了循环里的什么？—— 手写解析梯度那两行（grad_w、grad_b）。
6. 训练循环的五个固定动作？—— 前向、算损失、算梯度、更新参数、记录/打印。
