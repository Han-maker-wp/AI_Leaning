## 4.1 从回归到分类：需要的是概率

二分类任务（垃圾=1/正常=0）的难点：标签是离散的 0/1，而 `w·x + b` 的输出是任意实数。

方案：**线性部分照旧算一个分数 z = w·x + b，再套一个函数把 z 压进 (0,1) 当概率**：

```
σ(z) = 1 / (1 + e^(−z))

p = σ(w·x + b)      p > 0.5 → 预测为正类
```

这个模型叫**逻辑回归（logistic regression）**——名字带「回归」是因为它的骨架就是线性回归，只是输出套了 σ；但用途是分类。历史包袱，别纠结。

> 🍿 彩蛋｜「回归」二字是历史遗留：逻辑回归本质是分类算法，名字里的「回归」纯属历史遗留，骗倒过无数新人——包括不少面试官。看到它请自动脑内翻译成「逻辑分类」，免得日后听到「用回归做分类」时怀疑人生。

sigmoid 的两个好处：

1. 单调、值域 (0,1)，天然当概率用
2. 求导极简：σ'(z) = σ(z)(1 − σ(z))——下一节梯度变漂亮全靠它

> ☕ Java 视角：等价于「评分服务 + 阈值规则」：线性层打分，sigmoid 归一化成分数概率，0.5 当阈值开关。工程上你早就见过这个套路（风控评分卡）；ML 的区别是「分数怎么来」由训练决定。

## 4.2 交叉熵损失：惩罚「自信的错误」

概率输出配的损失是**二元交叉熵（BCE）**：

```
L = −(1/n) Σᵢ [ yᵢ·log pᵢ + (1−yᵢ)·log(1−pᵢ) ]
```

别被式子吓到，它的行为极其讲理。取单个样本看两种情况：

- 真值 y=1：L = −log p。p→1 时 L→0（对得很自信，不罚）；p→0 时 L→∞（**自信地错了，往死里罚**）
- 真值 y=0：L = −log(1−p)，对称同理

对比 MSE：MSE 对「自信的错误」最多罚到有限值，交叉熵罚向无穷——**分类任务要的就是这种「越自信错得越离谱」的惩罚结构**。概率视角再补一刀（你熟悉的语言）：对伯努利似然取 −log，得到的正是交叉熵。与第 2 课「高斯噪声 → MSE」完美对偶：**换噪声假设 = 换损失函数**。

## 4.3 梯度：形式与线性回归惊人一致

对 p = σ(w·x + b) 与 BCE 复合求偏导，链式法则中间的 σ'(z) = σ(1−σ) 恰好与交叉熵的导数相消，留下：

```
∂L/∂w = (1/n) Σᵢ (pᵢ − yᵢ) · xᵢ = (1/n) Xᵀ(p − y)
∂L/∂b = (1/n) Σᵢ (pᵢ − yᵢ)
```

与第 3 课线性回归的梯度 `2/n · Xᵀ(ŷ−y)` 只差常数因子——**「预测概率减真值」乘回特征**。这不是巧合：sigmoid+交叉熵与 线性+MSE 同属广义线性模型的指数族配对（链接函数 ↔ 损失函数），你有足够的数学自己把消项过程补全（练习 3 用数值验证）。工程含义：训练循环一个字不用改，只换前向和损失。

## 4.4 评估：混淆矩阵与 P/R/F1（手算一遍）

分类的「对错」有结构。以「垃圾邮件检测」（正类=垃圾）为例，在 100 封测试邮件上（其中 30 封垃圾、70 封正常），模型预测结果：

```
                    预测垃圾(1)    预测正常(0)
实际垃圾(1)  30封      TP = 24        FN = 6
实际正常(0)  70封      FP = 4         TN = 66
```

- **TP**（真阳性）：垃圾且被判垃圾，24 封
- **FN**（假阴性）：垃圾漏判成正常，6 封
- **FP**（假阳性）：正常误判成垃圾，4 封
- **TN**（真阴性）：正常且判正常，66 封

四个指标逐个算（务必跟算一遍）：

```
准确率 Accuracy = (TP + TN) / 全部 = (24 + 66) / 100 = 0.90
精确率 Precision = TP / (TP + FP) = 24 / 28 ≈ 0.857   「报出来的里多少真是垃圾」
召回率 Recall    = TP / (TP + FN) = 24 / 30 = 0.800   「真垃圾里抓住了多少」
F1 = 2PR / (P + R) = 2×0.857×0.800 / (0.857+0.800) ≈ 0.828   P 与 R 的调和平均
```

精确率与召回率天然存在张力：把判定阈值从 0.5 提到 0.9（更谨慎），误报变少精确率升、但漏报变多召回率降；反之亦然。F1 用调和平均同时扣罚两者短板（调和平均对较小值敏感——数学上就是把「偏科」当缺陷）。

## 4.5 为什么不能只看准确率：类别不平衡

设想癌症筛查，1% 的人患病。写一个「无脑预测全部健康」的模型：

```
Accuracy = 99%      ← 看起来很棒
Recall   = 0/1 = 0  ← 一个病人都没抓住，灾难
Precision = 0/0 无定义（没有预测出任何正类）
```

**类别不平衡时，准确率被多数类淹没，失去意义**。此时必须看 P/R（或多分类看每类的 P/R + 宏平均）。垃圾邮件、欺诈检测、罕见病诊断、缺陷检测全是长尾分布——「准确率 99%」在这类任务里可能是最差的模型。习惯：分类任务先看混淆矩阵，再谈任何单一指标。

> ☕ Java 视角：这就是「接口测试覆盖率 90% 但核心路径没测」的指标陷阱——单一聚合指标掩盖结构性缺陷。混淆矩阵 = 分类版的测试报告明细。

## 4.6 完整代码：训练 + loss 曲线 + 决策边界

与 `code/L04_logistic_regression.py` 相同（较长，核心结构已在 4.3 讲透，重点看注释）：

```python
"""L04：纯 numpy 逻辑回归二分类——训练循环 + loss 曲线 + 决策边界。

运行前：uv pip install numpy matplotlib
输出：L04_loss_curve.png 与 L04_decision_boundary.png
"""
import numpy as np
import matplotlib.pyplot as plt


def sigmoid(z: np.ndarray) -> np.ndarray:
    """σ(z) = 1 / (1 + e^{-z})，把任意实数压进 (0,1) 当概率用。"""
    return 1.0 / (1.0 + np.exp(-z))


def bce_loss(p: np.ndarray, y: np.ndarray) -> float:
    """二元交叉熵：-(1/n) Σ [y·log p + (1-y)·log(1-p)]。

    np.clip 把 p 限制在 [eps, 1-eps]，避免 log(0) 产生 inf。
    """
    eps = 1e-12
    p = np.clip(p, eps, 1.0 - eps)
    return float(-np.mean(y * np.log(p) + (1.0 - y) * np.log(1.0 - p)))


def make_blobs(rng: np.random.Generator, n_per_class: int = 150):
    """生成两个可分的二维高斯团簇：类 0 中心 (-2,-2)，类 1 中心 (2,2)。"""
    X0 = rng.normal(loc=-2.0, scale=1.2, size=(n_per_class, 2))
    X1 = rng.normal(loc=2.0, scale=1.2, size=(n_per_class, 2))
    X = np.vstack([X0, X1])                                    # (2n, 2)
    y = np.hstack([np.zeros(n_per_class), np.ones(n_per_class)])  # (2n,)
    return X, y


def main() -> None:
    rng = np.random.default_rng(42)
    X, y = make_blobs(rng)

    w = np.zeros(X.shape[1])                   # (2,) 参数初始化
    b = 0.0
    lr = 0.1
    epochs = 200
    history = []

    # 训练循环（结构与 L03 完全一致：前向 → 损失 → 梯度 → 更新）
    for epoch in range(1, epochs + 1):
        p = sigmoid(X @ w + b)                 # (2n,) 预测为正类的概率
        loss = bce_loss(p, y)

        error = p - y                          # (2n,)
        grad_w = X.T @ error / len(y)          # (2,)  梯度与线性回归同构
        grad_b = float(np.mean(error))

        w -= lr * grad_w
        b -= lr * grad_b
        history.append(loss)
        if epoch % 40 == 0 or epoch == 1:
            acc = float(np.mean((p >= 0.5) == y))
            print(f"epoch {epoch:3d} | loss = {loss:.4f} | acc = {acc:.3f}")

    # 混淆矩阵（演示计算方法；正经做法应在「测试集」上算）
    pred = (sigmoid(X @ w + b) >= 0.5).astype(int)
    tp = int(np.sum((pred == 1) & (y == 1)))
    fp = int(np.sum((pred == 1) & (y == 0)))
    fn = int(np.sum((pred == 0) & (y == 1)))
    tn = int(np.sum((pred == 0) & (y == 0)))
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    print(f"\n混淆矩阵 TP={tp} FP={fp} FN={fn} TN={tn}")
    print(f"precision={precision:.3f} recall={recall:.3f} "
          f"f1={2 * precision * recall / (precision + recall):.3f}")

    # 图 1：loss 下降曲线
    plt.figure(figsize=(6, 4))
    plt.plot(history)
    plt.xlabel("epoch")
    plt.ylabel("BCE loss")
    plt.title("Logistic regression training")
    plt.grid(True)
    plt.savefig("L04_loss_curve.png", dpi=150)

    # 图 2：决策边界——网格逐点预测概率并着色
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 200),
                         np.linspace(y_min, y_max, 200))
    grid = np.column_stack([xx.ravel(), yy.ravel()])   # (200*200, 2)
    zz = sigmoid(grid @ w + b).reshape(xx.shape)       # 每个网格点的正类概率

    plt.figure(figsize=(6, 5))
    plt.contourf(xx, yy, zz, levels=20, cmap="RdBu", alpha=0.6)   # 概率热力图
    plt.scatter(X[y == 0, 0], X[y == 0, 1], s=12, c="blue", label="class 0")
    plt.scatter(X[y == 1, 0], X[y == 1, 1], s=12, c="red", label="class 1")
    plt.xlabel("x1")
    plt.ylabel("x2")
    plt.title("Decision boundary (p >= 0.5)")
    plt.legend()
    plt.savefig("L04_decision_boundary.png", dpi=150)
    plt.show()
    print("图已保存：L04_loss_curve.png / L04_decision_boundary.png")


if __name__ == "__main__":
    main()
```

决策边界的画法值得记：`meshgrid` 造网格 → `ravel` + `column_stack` 变成 (N,2) 的「批量预测」→ `contourf` 按概率上色。p=0.5 的等值线就是分界面。对线性模型它必是直线/平面（思考：为什么？）。

## 练习

1. 把两个团簇中心改近（-0.5 与 0.5），重跑并观察边界与 F1 变化。提示：可分性下降，重叠区错误不可避免，recall/precision 同时受损。
2. 把判定阈值从 0.5 改成 0.8，重新统计 P/R/F1，验证此消彼长。提示：只改 `(p >= 0.8)` 一处。
3. 数值验证梯度：任取 j，用中心差分 (L(w+εeⱼ) − L(w−εeⱼ)) / (2ε) 对比解析梯度的第 j 个分量。提示：ε=1e-5，两者应几乎相等——这是你以后调试深度模型梯度的救命技能。
4. 类别不平衡实验：把类 0 样本砍到 20 条重跑，对比 accuracy 与 recall 的分歧。提示：accuracy 依然好看，recall 揭示真相。

## 小结与自测

1. sigmoid 的两大利好？—— 输出 (0,1) 可当概率；导数 σ(1−σ) 让梯度形式极简。
2. 交叉熵为何「惩罚自信的错误」？—— y=1 而 p→0 时 −log p → ∞，越自信罚越重。
3. 逻辑回归的梯度形式？—— (1/n)Xᵀ(p−y)，与线性回归 MSE 梯度只差常数因子。
4. Precision 与 Recall 各回答什么？—— 报出的正类里多少是真的 / 真正类里抓住了多少。
5. 类别不平衡时准确率为什么失效？—— 全猜多数类即得高准确率，指标被多数类淹没。
6. 决策边界怎么画的？—— 网格批量预测概率 + 等值线着色，p=0.5 处即边界。
