# 第 5 课：过拟合与正则化

> 🎬 开场钩子：两个模型同台竞技：甲的训练误差低到 0.0001，乙只有 0.4——先别急着押注甲。换一批从没见过的数据，甲当场失控，乙依旧稳定。这就是过拟合：背题学霸「模拟考封神，高考换题就崩」。本课教你用曲线诊断这个病，用 L1/L2、交叉验证与早停治这个病。

⏱ 建议学时：2 小时

3. 写出 L2/L1 正则化的损失与梯度，给出各自的几何与统计直觉
4. 说明 k 折交叉验证的流程与用途，会读学习曲线
5. 理解早停（early stopping）为什么算正则化，并预告深度学习的过拟合

## 5.1 过拟合：背题 vs 会做题

定义式症状：**训练误差很低，测试（验证）误差明显更高**——两条曲线随训练进行分叉。

类比：学生把题库答案全背下来，原题满分、新题不会。模型「记住」了训练样本的噪声细节，而不是学到可泛化的规律。反过来，训练误差和测试误差**都高**，叫**欠拟合**——模型太简单，连训练集的规律都没抓住。

三个来源：模型容量过大（参数太多）、数据太少、训练过久。第 1 课「不能只看训练集表现」在这里兑现成方法论。

> ☕ Java 视角：像把业务规则硬编码成一张超大的 if-else 查找表——训练数据上永远「命中」，遇到没见过的输入就崩。泛化 = 从个案中抽象出规则，和你设计抽象时「不要为单个 case 打补丁」是同一种判断力。

## 5.2 诊断：让多项式阶数替你演示

用「多项式阶数」当模型复杂度的旋钮最直观：数据来自 sin 曲线 + 噪声，分别用 1 阶、3 阶、14 阶多项式拟合（完整代码在 `code/L05_overfitting_demo.py`，这里给核心）：

```python
coeffs = np.polyfit(x_train, y_train, degree)   # 最小二乘拟合
poly = np.poly1d(coeffs)                        # 系数变函数
train_mse = np.mean((y_train - poly(x_train)) ** 2)
test_mse = np.mean((y_test - poly(x_test)) ** 2)
```

典型结果（15 个训练样本时）：

```
degree | train MSE | test MSE | 诊断
   1   |   0.4x    |   0.4x   | 欠拟合：两条误差都高
   3   |   0.06    |   0.07   | 恰当：两条都低且接近
  14   |  ≈0.0001  |   爆炸   | 过拟合：训练近完美，测试失控
                          （14 阶曲线疯狂穿行每个训练点）
```

把「degree → 复杂度」换成「模型参数量」完全同构：这张表就是给任何模型做体检的模板。

## 5.3 偏差-方差权衡

同一份数据换不同的训练子集训练，模型预测的波动可以分解成：

- **偏差（bias）**：平均预测离真规律有多远——模型太简单带来的系统性误差（欠拟合高偏差）
- **方差（variance）**：换个训练集预测就大变——模型太敏感于样本噪声（过拟合高方差）
- **不可约误差**：噪声本身，再好的模型也消不掉

```
测试误差 ≈ 偏差² + 方差 + 噪声

复杂度 ↑ → 偏差 ↓，方差 ↑（存在 sweet spot）
```

这个分解解释了所有「药方」的原理：加数据降方差、加正则降方差、升模型容量降偏差——调模型就是在偏差与方差之间找平衡点。深度学习有趣的反例（双下降现象）以后再聊，经典框架先建立。

## 5.4 L2 与 L1 正则：给参数上「缰绳」

思路：既然过拟合来自「参数太自由」，就在损失里加一项**嫌恶大参数**的罚项：

```
L2（Ridge）：  L = MSE + λ·Σⱼ wⱼ²          （w 的欧氏范数平方）
L1（Lasso）：  L = MSE + λ·Σⱼ |wⱼ|          （w 的 L1 范数）
```

λ 是正则强度超参数：λ=0 退回原始问题；λ→∞ 参数被压成 0（欠拟合）。对 L2，梯度只需加一项 `2λw`——更新时每次把 w 朝 0 拽一小步，所以深度学习里 L2 的名字就叫 **weight decay（权重衰减）**，你会天天见到。

两者的直觉差异（你的线代/优化直觉可直接迁移）：

- **L2**：把权重整体压小、偏好分散取值。几何上，二次罚项的等值线是圆，与损失椭圆相切处一般不在坐标轴上——各维权重都被均匀「揉小」，函数变平滑，不追噪声
- **L1**：菱形等值线的尖角顶点恰在坐标轴上，最优解容易落在角上 → 部分 wⱼ 精确为 0——**稀疏**，天然的「特征选择」

统计视角一句话：L2 对应参数的高斯先验，L1 对应拉普拉斯先验（最大后验估计），与你已知的贝叶斯连线。

> 🍿 彩蛋｜Lasso 是个精心设计的缩写：全称 Least Absolute Shrinkage and Selection Operator（最小绝对收缩与选择算子），把它的两大本领——压小权重、选出特征——全写进了名字；缩写又恰好拼成「套索」，正是把多余特征套住拖走的意象。

## 5.5 交叉验证与学习曲线

**k 折交叉验证（k-fold CV）**：把训练数据切 k 份（常用 5），轮流用 1 份当验证、其余当训练，得到 k 个分数取平均。解决两个问题：

1. 单次切分运气成分大（第 1 课练习 1 亲眼看过波动），k 次平均更稳
2. 小数据集上「浪费」在验证上的数据被反复复用

用途：**调超参数**（如 λ、degree）——对每组候选超参做一次 k 折 CV，选平均分最好的。纪律：测试集全程不参与，最终只评估一次。

**学习曲线（learning curve）**：横轴样本量，纵轴训练/验证误差，两线走势速读表：

```
情形          训练误差      验证误差        两线间距    诊断 → 药方
A  ─────     高且贴近      高且贴近        很小        高偏差（欠拟合）→ 升容量/加特征
B  ─────     低            高、明显更高    很大        高方差（过拟合）→ 加数据/正则/早停
C  ─────     低            仍在下降        收窄中      加数据还有红利，继续采数据
```

另一版本横轴是训练轮数/迭代数，直接展示「验证误差开始回升」的时刻——引出下一节。看图口诀：**先看两线高低（绝对水平），再看两线间距（过拟合程度），最后看走势（数据/训练还有没有红利）**。

## 5.6 早停与其他手段

**早停（early stopping）**：训练时盯着验证集 loss，一旦不再下降（或容忍 patience 轮仍不降）就停止训练。为什么算正则化：它限制了参数从初始点（通常是 0 附近）走远的总步数，等效于约束参数范数——与 L2 异曲同工，而且零成本。深度学习最常用的正则手段之一，第 2 阶段训练脚本里标配。

常规军火库一览（后面阶段都会重逢）：

- 加数据 / 数据增强（图片翻转、同义改写）
- 正则化（L1/L2/weight decay）
- 早停
- 简化模型（降容量）
- 集成（随机森林的 bagging 也是降方差，第 6 课见）
- 深度学习专属：dropout（预告：训练时随机失活一部分神经元）

## 5.7 伏笔：深度学习时代过拟合为何更凶

参数量远超样本量（GPT 级模型参数 10¹¹，训练语料token 10¹³ 但任务上仍会过拟合特定分布）；表达力极强 → 方差天然大。所以微调 LLM 时你会面对：小样本任务过拟合（几步就背住训练集）、灾难性遗忘（正则化的另一种形态）。本课的概念（训练/验证分叉、early stopping、weight decay）会原封不动出现在 LoRA 微调脚本的参数里——地基就在这里。

## 5.8 实战诊断清单（贴在显示器边上的那种）

拿到任何一个「效果不行」的模型，按序排查：

1. 先看训练误差：训练误差就高 → 欠拟合方向（加容量/加特征/训更久），别急着加正则
2. 训练误差低、验证高 → 过拟合方向：先试最便宜的早停与 weight decay，再考虑简化模型
3. 两者都低但上线就崩 → 检查数据泄漏与训练/线上数据分布差异（第 1 课的老朋友）
4. 小数据集上调参 → 一律 k 折交叉验证，别信单次切分
5. 每次只改一个变量并记录——否则你的「变好」无法归因，无法复现

## 小结与自测

1. 过拟合的定义式症状？—— 训练误差低 + 测试误差高，两线分叉。
2. L1 与 L2 的效果差异？—— L2 整体压小权重（平滑），L1 造稀疏（部分权重精确为 0，可做特征选择）。
3. 偏差与方差分别对应什么病？—— 高偏差=欠拟合（没学到规律），高方差=过拟合（对样本扰动过敏）。
4. k 折交叉验证用来干什么？—— 更稳地调超参数与选模型，测试集留到最后。
5. weight decay 是什么？—— L2 正则在深度学习优化器里的名字（每次更新额外减 2λw）。
6. 早停为什么算正则化？—— 限制参数离开初始点的总距离，等效约束参数范数。
