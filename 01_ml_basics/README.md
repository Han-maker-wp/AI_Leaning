# 阶段 1：机器学习基础

> 前置：完成阶段 0 验收（能独立写命令行 todo 工具、能读懂 NumPy 向量化代码）。
> 本阶段目标不是「会用库」，而是把「从数据学规则」的心智模型焊牢——它是后面 PyTorch 与微调 LLM 的地基。

## 阶段目标

1. 建立「从数据学规则」的心智模型：模型 = 参数化的函数，训练 = 调参数
2. 彻底掌握三个核心概念：**损失函数**（好坏的度量）、**梯度下降**（怎么变好）、**过拟合**（为什么看起来很好其实不行）
3. 能用纯 NumPy 从零实现线性回归与逻辑回归的完整训练循环
4. 会用 scikit-learn 的 fit/predict/Pipeline 范式完成一个小项目

## Checkpoint：纯 NumPy 从零实现逻辑回归（阶段通关标准）

第 6 课结束后、进入阶段 2 之前，不看讲义答案（可查 NumPy 文档），独立完成 `logistic_from_scratch.py`：

1. 用 NumPy 生成二分类数据（两个高斯团簇即可），或加载手头任何二分类数据
2. 手写 sigmoid 与二元交叉熵损失
3. 手写解析梯度（提示自己：`(1/n) Xᵀ(p−y)`），实现完整训练循环
4. 训练过程中记录 loss，训练结束画出 **loss 下降曲线**
5. 训练结束画出 **决策边界**（网格逐点预测 + 等高线着色 + 样本散点）
6. 不许调用 sklearn 的模型类；可以最后用 `sklearn.linear_model.LogisticRegression` 验证你的准确率在同一水平

通过标准：

- loss 曲线（近似）单调下降并趋于平稳
- 决策边界能合理分隔两类样本
- 你能对着代码逐行解释梯度公式的来历（允许推一步停下来在纸上推完）

## 学习方式约定

- 本阶段代码是主角：每课的 `code/` 示例先跑通，再做「改参数观察行为」的实验（改学习率、改噪声、改样本量）
- 公式不从零教数学——重点永远是「公式里的每个符号 ↔ 代码里的哪个数组、哪一行」
- 遇到 Java 视角标记 `> ☕ Java 视角：...` 是为你定制的类比，别跳过
