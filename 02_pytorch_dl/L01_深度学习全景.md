## 1.2 你已经会一半了：线性回归就是一个神经元

回顾你在前置课程手写过的 numpy 线性回归：

```
y_hat = w * x + b
loss  = mean((y_hat - y)^2)
# 手推梯度公式，循环更新 w、b
```

单个「神经元」干的事几乎一模一样，只是输入从一个数变成 n 个数：

```
z = w1*x1 + w2*x2 + ... + wn*xn + b     # 线性组合，就是矩阵乘 x @ W + b
a = f(z)                                 # f 是激活函数——唯一的差别
```

- 线性回归：`f(z) = z`（恒等，什么也不做）；
- 经典神经元：`f` 是 sigmoid 或 tanh；现代网络里更多是 ReLU。

所以：**神经元 = 你熟悉的线性模型 + 一个非线性函数**。机器学习课学过的一切（损失函数、梯度下降、过拟合）原封不动地继续适用。深度学习不是推倒重来，是在旧地基上盖楼。

再看形状视角：一个神经元是向量内积（`[n] @ [n] -> 标量`）；一层 100 个神经元就是矩阵乘（`[batch, n] @ [n, 100]`）。你在 numpy 里写的 `X @ W`，在神经网络里有个名字：全连接层。这也解释了前置课程为什么强调矩阵运算——它是所有深度学习框架的基本操作。

## 1.3 为什么必须有非线性激活

论断：**如果层与层之间没有非线性激活，那么不管叠多少层，整个网络仍等价于一个线性层**。100 层「深度」网络塌缩成一层，谈何「深度」学习。

手推（2 层为例）：

```
第 1 层：h = W1·x + b1
第 2 层：y = W2·h + b2
代入：
y = W2·(W1·x + b1) + b2
  = (W2·W1)·x + (W2·b1 + b2)      ← 合并同类项
  = W'·x + b'                      ← 就是一个线性层
```

numpy 验证（完整可运行）：

```python
import numpy as np

if __name__ == "__main__":
    rng = np.random.default_rng(0)

    W1, b1 = rng.normal(size=(4, 3)), rng.normal(size=(4,))  # 3 维输入 -> 4 维
    W2, b2 = rng.normal(size=(2, 4)), rng.normal(size=(2,))  # 4 维 -> 2 维
    x = rng.normal(size=(3,))

    # 两层线性层直接堆叠（中间没有激活函数）
    y_two_layer = W2 @ (W1 @ x + b1) + b2

    # 数学上必然存在的等价单层
    W_eq = W2 @ W1
    b_eq = W2 @ b1 + b2
    y_one_layer = W_eq @ x + b_eq

    print("两层与一层输出是否相同:", np.allclose(y_two_layer, y_one_layer))  # True
```

再补一句几何直觉：线性变换只能「旋转、拉伸、平移」空间，叠多少次决策边界仍是直线/平面。而哪怕最简单的分类问题（异或 XOR）都需要弯曲的边界——弯的能力来自激活函数。ReLU（`max(0, z)`）是现代最常用的激活：简单、快、正区间不饱和（不饱和为什么重要，见本课练习 4）。

## 1.4 MLP：把神经元组装成网络

MLP（Multi-Layer Perceptron，多层感知机，也叫全连接网络）=「线性层 + 激活函数」的堆叠：

```
 输入层 (3)         隐藏层 1 (4, ReLU)      隐藏层 2 (4, ReLU)      输出层 (2)
                  ┌─ ○ ○ ○ ○ ─┐          ┌─ ○ ○ ○ ○ ─┐
  x1 ● ──────────►│           │─────────►│           │─────────►  ●  ●
  x2 ● ──────────►│  全连接   │─────────►│  全连接   │  (无激活或
  x3 ● ──────────►│           │─────────►│           │   softmax)
                  └───────────┘          └───────────┘
  每条连线一个权重 w；每个隐藏/输出神经元一个偏置 b；隐藏层后接 ReLU
```

参数量怎么数：每层 = `in × out`（权重）+ `out`（偏置）。上图：

```
层1: 3×4 + 4 = 16
层2: 4×4 + 4 = 20
层3: 4×2 + 2 = 10
合计 46 个参数
```

为什么叫「隐藏层」：它们的输出不是人工指定的目标，而是网络自己学出来的中间表示。低层学简单特征、高层组合成抽象特征（视觉网络里著名例子：边缘 → 纹理 → 部件 → 物体）。这个「逐层组合表示」的思想叫表示学习，是深度学习相对传统机器学习最大的范式差异——以前特征靠人手工设计（特征工程），现在特征也是学出来的。

理论保证一句话：带一个隐藏层的 MLP 是万能近似器（能逼近任意连续函数）。但定理只说「存在」，不告诉你需要多大、更不保证梯度下降能找到——所以实践里要靠「深」与调参，这正是后面 8 课的内容。

> 🍿 彩蛋｜万能近似定理的「理论上」：1989 年前后，Cybenko、Hornik 等人证明了单隐层网络理论上能逼近任意连续函数。注意「理论上」三个字——定理只保证存在，不保证网络够小，更不保证梯度下降能找到它。这三个字骗过的懒人，能绕地球一圈。

## 1.5 「深度」指什么

- 深度 = 隐藏层数量（层数越多越「深」）。
- 为什么追求深而不是把一层做得很宽（更多神经元）？因为很多自然函数是层次化组合的：物体由部件构成、部件由边缘构成；句子由短语构成、短语由词构成。深的结构能用指数级更少的参数表示这类组合函数。类比写代码：一个 1000 行的平铺函数 vs 10 层嵌套调用的模块化设计，后者复用结构、总代码量小得多。
- 但深度带来训练难题（梯度消失/爆炸——第 2 阶段 L03、L09 反复拆解），2015 年 ResNet 的残差连接是著名解药，第 3 阶段讲 Transformer 时它还会出场。

## 1.6 为什么是现在：算力 + 数据 + 架构

神经网络理论 1980 年代就基本成型（反向传播 1986 年广泛传播），为什么直到 2012 年才爆发？

1. **算力**：GPU 本为图形渲染设计，恰好擅长神经网络需要的大规模矩阵乘。2012 年 AlexNet 用 2 块 GPU 训练，拿下 ImageNet 竞赛冠军，误差率大幅领先第二名，直接引爆行业。
2. **数据**：互联网产生了百万/亿级标注数据（ImageNet 约 1400 万张图）。传统机器学习算法的性能随数据量先升后平（饱和），而神经网络几乎随数据与参数量持续提升。
3. **架构与训练技巧**：ReLU、残差连接（ResNet, 2015）、BatchNorm、Adam、dropout 等让「深」网络真正训得动；2017 年 Transformer（arXiv 1706.03762）把这一套推向语言，开启大模型时代。

对你的路线图：4 个月后你要微调的 LLM，骨架就是 2017 年那篇论文的 Transformer（第 3 阶段精读）。而让 Transformer 训练起来的工程骨架——训练循环、梯度下降、张量运算——正是接下来 8 课要打的地基。

> 🍿 彩蛋｜游戏显卡成了 AI 硬通货：AlexNet 2012 年训练用的是两张 GTX 580——彻头彻尾为玩家设计的游戏卡。游戏显卡从此意外成为 AI 行业的硬通货，「挑显卡」也成了炼丹师的入门仪式。

## 小结与自测

1. 神经元与线性回归的关系？
   答：神经元就是线性回归的向量化 `z = xW + b`，外加一个非线性激活 `a = f(z)`。
2. 为什么必须非线性激活？
   答：线性层堆叠在数学上等价于单个线性层，网络表达能力塌缩回线性模型。
3. 隐藏层的作用是什么？
   答：学习中间表示，逐层把原始特征组合成抽象特征（表示学习）。
4. 「深度」指什么、为何深比宽好？
   答：隐藏层数；层次化组合的函数用深层结构表示，参数效率高得多。
5. 深度学习 2012 年爆发的三要素？
   答：GPU 算力、互联网级数据、架构与训练技巧（ReLU/残差/Adam 等）成熟。
