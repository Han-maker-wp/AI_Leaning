# 第 2 课：序列建模：RNN 与 LSTM 概览

> 🎬 开场钩子：2017 年之前，NLP 的王座属于 RNN 与 LSTM——翻译、语言模型全是它们的天下；2017 年之后，新架构里几乎找不到它们的身影。一门技术从「行业标配」到「被请出场」，只用了短短几年。今天搞清楚它们当年强在哪、后来输在哪——这也是理解 Attention 的最短路径。

⏱ 建议学时：1.5 小时

## 本课目标

1. 能列出序列建模相对普通分类的三大难点；
2. 能写出 RNN 的更新式并画出按时间展开的示意；
3. 能用「连乘」直觉解释梯度消失，并说明它为何伤害长距离依赖；
4. 能用一句话分别说清 LSTM 三个门的作用；
5. 能说清 RNN 被 Attention 取代的三个理由。

定位说明：本课是概览——理解到「能说清为什么被 Attention 取代」即可，不深钻公式与变体。

## 2.1 序列建模难在哪

分类任务的输入是固定长度向量；语言是**变长、有顺序、有远距离依赖**的信号：

- 变长：一句话 5 个词，另一句 50 个词，模型结构却要统一；
- 顺序敏感：「狗咬人」≠「人咬狗」，词袋类表示天然失败；
- 远距离依赖：「我出生在法国，……（省略 40 词）……，所以我说一口流利的___」——「法国」要跨越几十步影响句尾的预测。

需要一个能「读入任意长度、记住历史、按需取用」的机制。2017 年前的答案是循环网络（RNN），这也是理解 Attention 的最佳起点——Attention 正是对 RNN 弱点的逐条回应。

## 2.2 RNN：隐藏状态传递

核心思想：维护一个隐藏状态 h，作为「到目前为止读到的内容的摘要」，每读一个新 token 更新一次：

```
h_t = tanh(W_x · x_t + W_h · h_{t-1} + b)

x_t：第 t 步输入（词向量）
h_{t-1}：上一步的摘要（"记忆"）
h_t：新摘要；每步的 h 可接输出层做预测
```

按时间展开（文字图）：

```
      x_1        x_2        x_3        x_4
       │          │          │          │
  ┌────▼───┐ ┌────▼───┐ ┌────▼───┐ ┌────▼───┐
  │  RNN   │►│  RNN   │►│  RNN   │►│  RNN   │     同一个单元、
  │  Cell  │h1 Cell   │h2 Cell   │h3 Cell  │h4    同一套参数 W
  └────────┘ └────────┘ └────────┘ └────────┘     重复使用
  h_0 = 0 ──►（沿箭头从左到右流动的就是"记忆"h）
```

优点鲜明：参数共享（一套 W 处理任意长度）、天然支持变长输入、每步有输出（可做生成）。2014 年前后机器翻译与语言模型的主力。

代价：**必须串行**——算 h_t 必须先算完 h_{t-1}。GPU 最擅长大规模并行，RNN 却把它晾着，序列越长越慢。

## 2.3 梯度消失：连乘效应

训练 RNN 要沿时间反向传播（BPTT）。从第 t 步回传到第 t-k 步的梯度里含有 W_h 与 tanh 导数的**连乘**：

```
∂L/∂h_{t-k} ≈ (∏ W_h · diag(tanh')) · ...
```

直觉版：`0.9 ** 50 ≈ 0.005`——每步衰减一点点，几十步后早期信号的梯度指数级归零（反之，若连乘因子模大于 1，则指数爆炸）。**梯度是训练信号**：梯度到不了远处，参数就学不到远距离的关系——「出生在法国」与句尾的「法语」在梯度意义上失联。这就是「梯度消失/爆炸」。

补充直觉：深 MLP 也有类似困扰（层间连乘），ResNet 的残差连接（第 4 课在 Transformer 里再见）与 LSTM 的门控都是给梯度修「高速公路」的不同方案。第 3 课你会看到 Attention 让任意两位置之间的梯度路径长度变成常数 1（直连）。

> 🍿 彩蛋｜传话游戏版梯度消失：梯度沿时间回传，像一队人玩传话游戏——每传一步走样一点，传到第 50 个人，原话早已面目全非。LSTM 的细胞状态相当于给关键信息发了张「免传话通行证」：沿传送带直达，不必逐人转述。

## 2.4 LSTM：给记忆装上门

长短期记忆网络（LSTM, 1997）在 RNN 单元内加了一条「细胞状态」传送带 c_t 和三个门（门 = sigmoid 输出 0~1 的开关，控制信息通过的比例）：

- **遗忘门**：c_t 里哪些旧记忆要丢掉（「法国」说完很久后还需要吗）；
- **输入门**：当前新信息哪些写入 c_t（现在这个「法国」要不要记下）；
- **输出门**：c_t 里哪些内容此刻输出为 h_t（说到「语言」时才把「法国」倒出来用）。

一句话总结：RNN 的记忆是「每步全量覆写」，LSTM 的记忆是「带读写开关的可累积账本」；梯度沿 c_t 的**加法**路径回传，避开连乘衰减——长依赖能力大幅改善，成为 2014~2017 年翻译与语言模型的标配（GRU 是它的两门简化版）。

> 🍿 彩蛋｜LSTM 的名字很诚实：Long Short-Term Memory，长短期记忆——名字长成这样，说明起名时已经不打算装了。它 1997 年出生，比这套讲义的读者里不少人都年长，如今在 Transformer 照不到的边缘场景仍偶尔上岗。

不必记门的具体公式，把「门控 = 可学习的开关」带走即可——Transformer 的注意力本质上是一种更泛化的可学习开关：每步自己决定从历史里取多少、取哪里。

## 2.5 RNN 时代怎么做文本生成

语言模型（第 8 课亲手写）的定义：P(x_t | x_1..x_{t-1})。RNN 的生成流程：

```
1. 给开头词，逐步算出 h
2. h -> 输出层 -> softmax -> 下一个词的概率分布
3. 从分布采样（或取最大）出下一个词
4. 把新词当输入，回到 2，直到生成结束符
```

这个「自回归循环」从 RNN 一路沿用至今——GPT 生成的就是这一套，只是把「用 h 摘要历史」换成了「用 Attention 直接看全历史」。记住这个骨架，第 5 课与第 8 课会有强烈既视感。

## 2.6 在 PyTorch 里长什么样（认脸即可，不必动手）

你在文档与开源代码里还会遇到 RNN/LSTM，认得出来即可。PyTorch 内置了现成层：

```python
import torch
import torch.nn as nn

if __name__ == "__main__":
    rnn = nn.RNN(input_size=4, hidden_size=8, batch_first=True)
    x = torch.randn(2, 5, 4)        # [batch, seq, feature]：2 句话、每句 5 个词、每词 4 维

    out, h_n = rnn(x)               # 前向一步完成（内部循环展开）
    print(out.shape)                # [2, 5, 8]  每个时间步的隐藏状态
    print(h_n.shape)                # [1, 2, 8]  最后一步的隐藏状态（"摘要"）
```

两个观察：`out` 给出每个时间步的 h（做序列标注用），`h_n` 只给最后一步（做分类/接续生成用）；`nn.LSTM` 用法相同，返回多一个细胞状态。本课不要求动手训练它——理解「隐藏状态在时间步之间传递」的结构，比会调 API 重要。

顺带一句时代背景：2014~2016 年翻译系统的主流是「双向 RNN encoder + RNN decoder」（seq2seq），外加注意力机制做对齐（Bahdanau attention——对，注意力最早就是给 RNN 打补丁的，2017 年才反客为主）。这段历史让你能准确理解论文标题 "Attention Is All You Need" 的挑衅意味：把 RNN 扔掉，只留注意力。

## 2.7 为什么被 Attention 取代

逐条对照 RNN 的弱点（下一课精讲 Attention 如何做到）：

| RNN 的问题 | Attention 的回应 |
|---|---|
| 串行计算，GPU 利用率低 | 所有位置**并行**计算（一个大矩阵乘） |
| 长距离梯度连乘衰减 | 任意两位置之间**直连**，梯度路径长度 1 |
| 固定维度 h 挤压全部历史 | 每步对全部历史**加权平均**，容量随序列增长 |

代价：注意力两两交互带来 O(n²) 计算量（第 3 课推导），长序列贵——这是一场「用计算换能力」的交易。GPU 时代算力便宜，交易划算。2017 年 Transformer 走通这条路（第 4 课），此后 NLP 全面转向。

## 小结与自测

1. 序列建模三大难点？
   答：变长、顺序敏感、远距离依赖。
2. RNN 为什么能处理任意长度？
   答：同一套参数按时间步重复使用，隐藏状态逐步传递。
3. 梯度消失的根源？
   答：跨时间步反向传播时 Jacobian 连乘，模小于 1 则指数衰减。
4. LSTM 三门各自一句话？
   答：遗忘门丢旧记忆、输入门写新记忆、输出门决定此刻输出什么。
5. RNN 被 Attention 取代的三个理由？
   答：全并行、长距离直连、容量随序列长度增长。
