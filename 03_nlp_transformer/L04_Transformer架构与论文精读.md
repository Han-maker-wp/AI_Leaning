## 4.1 精读方法：三遍读法

论文：**Attention Is All You Need**（Vaswani et al., 2017, arXiv 1706.03762）——深度学习史上引用最高的论文之一，也是你 4 个月后要微调的那些模型的骨架出处。

读论文不要逐字啃，用三遍读法：

1. **第一遍（10 分钟）**：标题、摘要、所有图和表。图 1（架构图）是全文地图，先看懂它；训练成本对比表也在这遍看；
2. **第二遍（1 小时）**：引言、方法各节的首末句、实验设置。回答「每个组件为什么存在」；
3. **第三遍（按需）**：公式与细节。注意力公式你已在第 3 课推过，剩下不多了。

建议顺序：先自己读图 1 猜结构，再回来对照本讲义核对——这个「先猜后对」的过程就是精读的训练法。配套资源：B 站有大量逐段讲解视频，但先自己读再看讲解，反过来就变成「收藏 = 学会」。

## 4.2 整体架构：encoder-decoder

论文任务是机器翻译（seq2seq），架构两大块（文字重绘）：

```
                       下一个目标词的概率分布 P(·)
                                ▲
                          Linear + Softmax
                                ▲
                      ┌─────────┴────────┐
       已生成的目标词 │     Decoder ×6    │
       （右移一位输入）│  ┌──────────────┐ │         ┌────────────────┐
      ──────────────►│  │Masked        │ │   K,V   │   Encoder ×6   │
      目标词 embedding│  │Self-Attn     │ │◄───────►│  Self-Attn     │
      + 位置编码      │  ├──────────────┤ │  交叉注意力  (双向)     │
                     │  │Cross-Attn    │ │         │  FFN           │
                     │  │(Q来自dec,    │ │         │                │
                     │  │ K,V来自enc)  │ │         └────────▲───────┘
                     │  ├──────────────┤ │                  │
                     │  │FFN           │ │            源句 embedding
                     │  └──────────────┘ │            + 位置编码
                     └──────────────────┘
        （每个子层外面都套一层「残差连接 + LayerNorm」）
```

要点：

- **Encoder**（双向）：读入源句（如中文），产出 n 个「上下文感知」的表示——每个位置都看过了全句；
- **Decoder**（单向）：逐个生成目标词（如英文）。带**因果掩码**的自注意力（只看已生成的左边）+ **交叉注意力**（Cross-Attention：Q 来自 decoder，K/V 来自 encoder 输出——「翻译当前词时去源句里找相关信息」，正是第 3 课 Q/K/V 查字典直觉的原生场景）；
- encoder 每层 2 个子层（自注意力 + FFN），decoder 每层 3 个（掩码自注意力 + 交叉注意力 + FFN）。

一个 decoder 层的前向（伪代码，d_model=512、h=8 头、FFN 宽 2048）：

```python
def decoder_layer(x_dec, x_enc):
    x = x_dec + MHA(LN(x_dec), mask=causal)      # 子层1：因果自注意力 + 残差
    x = x + CrossAttn(LN(x), x_enc)              # 子层2：交叉注意力 + 残差
    x = x + FFN(LN(x))                           # 子层3：FFN + 残差
    return x
```

> 🍿 彩蛋｜Encoder/Decoder，Web 老兵的老熟人：这对词你早就在别处用过——Netty 的 pipeline 里挂着 encoder/decoder 处理器，负责字节流与对象互转。Transformer 借这对词表达同一件事：把序列「编」成上下文表示，再把表示「解」回序列。编解码器的分工直觉，直接平移过来用。

## 4.3 位置编码：给无序的注意力补上顺序

第 3 课埋的问题：注意力是**置换等变**的——把输入 token 顺序打乱，各输出只是跟着重排，数值关系不变。换句话说**注意力天生不知道顺序**，而「我打他」和「他打我」对它是一样的。必须显式注入位置信息。

论文方案：每个位置 pos 生成一个 d_model 维向量，与词 embedding **相加**：

```
PE(pos, 2i)   = sin( pos / 10000^(2i/d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
```

直觉（不用推）：不同维度 i 用不同频率的正弦波——低维度振荡快（区分相邻位置），高维度振荡慢（区分远距离），像一组「多分辨率时钟」：秒针、分针、时针的组合能唯一编码任意时刻。选 sin/cos 还有一个性质：PE(pos+k) 可以表示成 PE(pos) 的线性变换（旋转），利于模型学习相对位置关系。

现代变体（名字了解即可）：GPT 用可学习的位置 embedding；LLaMA 等主流 LLM 用 RoPE（旋转位置编码，把相对位置编进 Q/K 的旋转角）。思想都一样：**注意力本身无序，顺序必须从外面注入**。

## 4.4 残差连接 + LayerNorm：深层网络的地基

**残差连接（residual）**：`输出 = x + Sublayer(x)`。为什么必须有：反向传播时梯度沿 `+` 直接流回输入（∂(x+F(x))/∂x = 1 + ∂F/∂x），那条恒等的 1 给梯度修了「高速公路」，不论多深都畅通——直接回应第 2 课的连乘衰减问题（ResNet, 2015 的核心贡献，CNN 时代验证、Transformer 继承）。副产品：每层只需学「增量修正」F(x)，比从零学整个映射容易。

**LayerNorm**：对**每个样本自己**的特征维做标准化（减均值、除标准差，再配可学习的缩放与平移）。作用：控制各层激活的数值范围，训练稳定、可用较大学习率。为什么不用 BatchNorm（传统 ML 里你可能听过的批量归一化）：序列任务的 batch 统计不稳定（变长、padding），且训练/推理行为不一致；LN 按样本归一，天然没有这两个问题。一句话分工：**残差保梯度，LN 保数值稳定**。

位置细节（Post-LN vs Pre-LN）：原论文 LN 在残差外（Post-LN：`LN(x + F(x))`），层数深了难训；现代实现多把 LN 放进残差内（Pre-LN：`x + F(LN(x))`，上面伪代码即此），无需热身也能稳定训练。看开源代码时注意这个差异即可。

## 4.5 FFN：逐位置的两层 MLP

```
FFN(x) = W2 · GELU(W1 · x + b1) + b2      （论文用 ReLU，现代多用 GELU）
```

形状：d_model(512) → 4×d_model(2048) → d_model(512)，对**每个位置独立**施加（不混合 token 间信息——混合是注意力的活）。参数量占大头（约三分之二）：一个流行的理解是注意力负责「路由/聚合信息」，FFN 负责「加工/存储知识」（key-value 记忆假说，名字了解即可）。

对照你学过的：这就是阶段 2 L01 的 MLP——Transformer = 注意力（新零件）+ MLP（旧零件）+ 残差/LN（工程粘合剂）。

## 4.6 Encoder vs Decoder 差异小结

| | Encoder | Decoder（生成式） |
|---|---|---|
| 自注意力方向 | 双向（看全句） | 因果掩码（只看左边） |
| 交叉注意力 | 无 | 有（K,V 来自 encoder） |
| 典型用途 | 理解类（分类/检索/抽取） | 生成类（翻译/摘要/对话） |
| 后继 | BERT | GPT |

训练小知识：翻译训练时 decoder 的输入是**标准答案右移一位**（teacher forcing）——每步预测下一个词，且因果掩码保证整句可以一次前向、并行算出所有位置的 loss；推理时没有答案，只能逐步自回归生成（慢）。「训练并行、推理串行」的不对称是生成式模型的通病，后面会反复遇到。

> 🍿 彩蛋｜Teacher forcing 的画面感：训练时不让模型沿用自己上一步的预测，而是把标准答案直接塞进下一步输入——像教练握着学员的方向盘：练车时纠正每一步，上路（推理）后才放手。名字里的 forcing，就是这个「硬塞」。

## 4.7 为什么今天的 LLM 是 decoder-only

原论文是 encoder-decoder（为翻译设计）。2018 年后 GPT 系证明纯 decoder 即可称霸，原因：

1. **任务统一**：一切任务都能写成「给前文、续下文」——翻译是「中文：xxx 英文：」，分类是「评论：xxx 情感：」，问答、代码、数学同理。一个生成目标覆盖所有任务，不用为每类任务改结构；
2. **训练高效**：自回归目标下整句一次前向就并行算出每个位置的 loss（因果掩码保证不泄漏），且所有无标注文本都能用——互联网规模的免费燃料；
3. **可缩放**：结构简单统一，堆层数堆数据即可，配 scaling laws（规模定律，名字了解）一路推到今天的大模型。encoder 的双向优势只在理解类基准上占优，而生成式模型用提示词也能做理解任务。

第 5 课正式讲这两条路线（BERT vs GPT）的分野与胜负。

## 小结与自测

1. 论文精读第一遍看什么？
   答：标题、摘要、图表——图 1 架构图是全文地图。
2. 位置编码为什么必须？
   答：注意力置换等变、天生无序；顺序信息必须显式注入（加到 embedding 上）。
3. 残差与 LayerNorm 各解决什么？
   答：残差给梯度开直路（深层可训）；LN 稳定每层的数值范围。
4. Cross-Attention 的 Q/K/V 来自哪？
   答：Q 来自 decoder 当前层，K/V 来自 encoder 的输出。
5. LLM 为什么 decoder-only？
   答：任务统一成续写、无标注语料可无限缩放、结构简单好堆规模。
