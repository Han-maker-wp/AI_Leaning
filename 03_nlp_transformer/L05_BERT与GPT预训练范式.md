# 第 5 课：BERT 与 GPT 预训练范式

> 🎬 开场钩子：2018 年的 NLP 圈流行给模型起芝麻街角色名：ELMo 打头阵，BERT 跟进，后来连 Big Bird、ERNIE 都来报到。为了挤进芝麻街，BERT 这个名字是先看中角色、再把 Bidirectional Encoder Representations from Transformers 的首字母「倒推」出来的。今天认识这条芝麻街背后真正的路线之争：完形填空的 BERT，与续写人生的 GPT。

⏱ 建议学时：2 小时

## 本课目标

1. 能对比「预训练 + 微调」与「从零训练」的成本结构；
2. 能讲清 BERT 的 MLM 目标与 [CLS]/[SEP]/[MASK] 特殊 token 的用途；
3. 能讲清 GPT 的自回归目标与 decoder-only 结构的对应；
4. 能用「预训练目标决定能力」解释 BERT 擅长理解、GPT 擅长生成；
5. 知道 BERT 做分类的标准接口（[CLS] 向量接分类头）。

## 5.1 预训练 + 微调：范式的由来

从零训练一个模型意味着：数据要为该任务专门标注、参数从随机初始化学起、每个任务重复烧一遍钱。预训练范式分两步：

1. **预训练**：用海量**无标注**文本（维基百科、网页），一个自监督目标（从文本自身构造监督信号，不需要人工标注）训练通用模型——学到语法、语义、世界知识；
2. **微调**：换上任务相关的小头（如分类头），用少量标注数据、小学习率调整。

一个你能秒懂的类比：先用整座图书馆学会中文语感（预训练），再用一本部门手册学会写周报（微调）。迁移学习在 CV（ImageNet 预训练）早已验证；2018 年前后 NLP 的「ImageNet 时刻」到来——BERT 与 GPT 同年发布，「预训练 + 微调」从此成为行业标准。你 4 个月后的毕业课题依然是这个范式，只是基座从亿级参数变成十亿级、微调手段从全参数变成 LoRA。

## 5.2 BERT：完形填空的通才

BERT（Bidirectional Encoder Representations from Transformers，2018，arXiv 1810.04805）：**只用 Transformer encoder**（双向），预训练目标是 **MLM（Masked Language Model，掩码语言模型）**——随机遮住约 15% 的 token，让模型凭**左右双向上下文**猜被遮的词：

```
输入：我 [MASK] 了机器学习课程
标签：          学
```

三个特殊 token（第 6 课会亲手 tokenize 看到）：

- `[CLS]`：加在句首。它在双向注意力里能看全句，训练时被塑造成「整句摘要」的槽位——分类任务就取它的向量；
- `[SEP]`：分隔两个句子（句对任务如蕴含、问答）；
- `[MASK]`：训练时的占位符。注意预训练与微调的 gap：微调后的真实输入没有 [MASK]，论文用 80%/10%/10%（遮 / 换成随机词 / 不动）的策略缓解——知道有这回事即可。

另有一个辅助任务 NSP（判断两句话是否相邻），后来 RoBERTa 的复现工作证明去掉更好——名字了解。

**双向是 encoder 的天赋**（理解任务本该看全句），但也断了生成的路：每个位置的表示都包含了未来信息，拿来按顺序「往外蹦词」等于抄答案——所以 BERT 天生不适合生成。

## 5.3 GPT：预测下一个词的生成机器

GPT（Generative Pre-trained Transformer，2018 起）：**只用 Transformer decoder**（因果掩码、单向），目标是**自回归语言模型**——预测下一个 token：

```
输入： 我   学   了   机器
标签：  学   了   机器  学习
       （每个位置都要预测自己的下一个词；因果掩码保证不泄漏，整句一次并行算 loss）
```

数学定义（第 2 课已铺垫）：P(x_1..x_n) = ∏ P(x_t | x_<t)。妙处在于**目标即产品**：生成就是不断预测下一词再采样（第 2 课的循环、第 8 课的实战）。于是产生了 GPT-3（2020，arXiv 2005.14165）展示的惊人性质：**不用微调，纯靠提示词（few-shot）就能做翻译、问答、推理**——任务说明本身写进前文，模型续写答案。规模推上去后这种能力持续增强，最终走到 ChatGPT 与你今天用的一切对话模型。

> 🍿 彩蛋｜GPT-1 的标题很朴素：2018 年第一代 GPT 的论文标题是 Improving Language Understanding by Generative Pre-Training——「用生成式预训练改进语言理解」，通篇没有一个吓人的词。谁能想到这套配方日后长成 GPT-3 的 1750 亿参数。顺带一提：复述这个数字时说错数量级的人，比想象中多得多。

## 5.4 预训练目标决定能力边界

一张表说清（本课最重要的对照）：

| | BERT | GPT |
|---|---|---|
| 结构 | encoder（双向） | decoder（因果掩码、单向） |
| 预训练目标 | 完形填空（MLM） | 预测下一词（自回归） |
| 每个位置的视野 | 左右全句 | 只有左边 |
| 擅长 | 分类 / 抽取 / 检索（理解） | 对话 / 翻译 / 写作（生成） |
| 不擅长 | 生成 | ——（理解任务可用提示词做） |
| 任务适配方式 | 加分类头微调 | 提示词 or 微调 |

类比：BERT 是完形填空满分选手（先看全卷再答题），GPT 是续写高手（只准看前文往下写）。考试形式（预训练目标）塑造了能力边界。

## 5.5 为什么生成时代 GPT 路线赢了

1. **目标即产品**：对话、写作、代码——商业价值集中在生成，而生成正是 GPT 的训练目标，零适配成本；
2. **统一接口**：第 4 课讲的「一切任务皆续写」——一个模型一份权重服务所有任务，工程与商业上碾压「每个任务一个微调模型」；
3. **缩放出智能**：自回归目标下数据无限（所有文本都是标签），scaling laws 持续兑现，few-shot、思维链等能力随规模涌现——MLM 目标没有展现出这条曲线；
4. BERT 系并未消失：理解类任务（搜索排序、语义检索、工业分类）上小而快、性价比高，今天仍在大量服役。两条路线是分工，不是生死——但通往通用模型的路只走了 decoder-only 这一条。

## 5.6 时间线与规模速查（建立坐标系）

把关键节点串起来，帮你建立「我们在哪」的坐标系：

```
2013  word2vec        词有了向量（第 1 课）
2017  Transformer     架构革命（arXiv 1706.03762，第 4 课）
2018  GPT-1 / BERT    预训练+微调范式确立（BERT: arXiv 1810.04805）
2019  GPT-2           15 亿参数，生成能力初显
2020  GPT-3           1750 亿参数，few-shot 涌现（arXiv 2005.14165）
2020  Scaling Laws    规模定律：算力/数据/参数的可预测收益
2022  ChatGPT         指令微调 + RLHF，生成时代全面到来
```

规模直觉（参数量级）：bert-base 约 1.1 亿（0.1B）；GPT-2 1.5B；GPT-3 175B；今天开源主流 LLM 在 7B~70B 量级。用阶段 2 L08 的公式换算：7B 模型 float32 推理约 28GB、int4 量化后约 3.5GB——这就是消费级显卡能跑大模型的原因，也是量化篇要解决的问题。

## 5.7 BERT 做分类的标准接口（为 L07 铺垫）

拿预训练 BERT 做情感分类的完整套路（下一课全部变成代码）：

```
输入文本
  → tokenizer（自动加 [CLS]/[SEP]，转 id）
  → BERT encoder（12 层双向注意力）
  → 取 last_hidden_state[:, 0]        # [CLS] 位置的向量 [batch, 768]
  → nn.Linear(768, num_labels)        # 新接的分类头（随机初始化）
  → 微调（预训练参数小步适应 + 新头正常学）
```

要点：BERT 主体参数是「预训练加载」的（已含语言知识），分类头是「新初始化」的；微调 = 让前者稍作适应 + 把后者学好。HuggingFace 把这套封装成 `BertForSequenceClassification`——第 7 课正式见面并训练它。

## 小结与自测

1. 预训练为什么能用无标注数据？
   答：自监督目标（MLM / 预测下一词）从文本自身构造监督信号，规模无上限。
2. [CLS] 的作用？
   答：句首槽位，双向看全句；微调后其向量作为整句表示接分类头。
3. BERT 与 GPT 的核心差异一句话？
   答：完形填空（双向理解）vs 预测下一词（单向生成）——目标决定能力边界。
4. 为什么 GPT 能 few-shot 完成任务而 BERT 不能？
   答：GPT 的使用方式（续写）与训练目标一致，任务说明写进前文即可；BERT 只能加头微调。
5. BERT 分类接口取哪个位置的输出？
   答：last_hidden_state 的 [CLS] 位置（或其池化）接 Linear 分类头。
