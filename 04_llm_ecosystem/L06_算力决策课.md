# 第 6 课：算力决策课——本地 GPU vs 云 GPU
> 🎬 开场钩子：租一张云 GPU 一小时几块钱，买一张高端卡上万块——毕业项目到底怎么选？今天不讲新知识，讲决策：算一笔明白账。这可能是全程最「省钱」的一课——决策错误的差价，够租几百小时卡。


> ⏱ 建议学时：2 小时（本课结束你应该能写下自己的算力决策清单）

## 本课目标

1. 能按需求档位（只推理 / QLoRA 微调 7B / LoRA / 全参）列出对应显存需求与候选卡型。
2. 能说清本地卡与云租卡的决策要素：使用频率、预算、数据敏感性、迭代速度。
3. 能走完一次云 GPU 租用全流程（以 AutoDL 为例）：选卡 → 环境 → 传数据 → 训练 → 收工。
4. 会读 nvidia-smi 的关键指标做训练监控与故障判断。
5. 产出一张毕业项目的成本测算表（量级 100~300 元）。

## 1. 决策框架：需求 → 资源 → 成本 → 决策

算力决策的第一原则：**先明确你要跑什么，再谈买什么**。用 L04 的显存公式把需求翻译成资源：

### 1.1 需求-资源对照表（本课程语境）

| 需求档位 | 显存需求（含余量） | 候选方案 |
|---|---|---|
| 只推理 0.5B~3B（量化） | CPU / 任何 GPU | 笔记本即可（L05 结论） |
| 只推理 7B int4 | 8~12 GB | RTX 3060 12G / 4060Ti 16G / 云入门卡 |
| 推理 7B fp16（或并发） | 16~24 GB | RTX 4090 24G / 云 4090 实例 |
| **QLoRA 微调 7B（毕业项目主档）** | **8~12 GB 起步，16~24 GB 舒适** | **云 4090 / 本地 24G 卡** |
| LoRA（bf16）微调 7B | 20~24 GB | 4090 24G / A100 级云卡 |
| QLoRA 微调 14B | 16~24 GB | 4090 24G |
| 全参微调 7B | ≈110 GB+ | 多卡 A100/H800——**超出个人范畴，本课程不涉及** |

### 1.2 本地 vs 云：核心权衡

| 维度 | 本地 GPU | 云 GPU |
|---|---|---|
| 一次投入 | 数千元~两万元 | 0（押金级） |
| 边际成本 | 电费 | 每小时几元，用完即止 |
| 随时可用 | 是 | 要抢卡（热门时段） |
| 迭代速度 | 睡觉时也在调参？不行也得行 | 可同时开多台并行实验 |
| 数据敏感 | 完全可控 | 上传到第三方（评估合规） |
| 环境运维 | 自己装驱动/CUDA | 平台镜像一键配好 |

**课程推荐路径**（算力未定时）：阶段 4 + 阶段 5 前期用 CPU/旧卡跑通全流程（0.5B~1.5B），
到 L05 实操和毕业项目时**按小时租云卡**（4090 级），毕竟能随时退租。重度长期使用（每天训练
数小时且持续数月）再考虑购入 24GB 级消费卡。

## 2. 本地 GPU 采购要点

### 2.1 显存优先原则

型号、算力、品牌都是第二位的——**显存不够，一切免谈**（L04 的账无法绕过）。宁可要显存大
一代的「慢卡」，不要显存卡线的「快卡」。个人微调的现实门槛线就是 **24GB**。

### 2.2 消费级 vs 数据中心卡

| | 消费级（RTX 4090 24G 等） | 数据中心（A100 80G 等） |
|---|---|---|
| 价格 | 1.5 万元级 | 十万元级，个人一般只能租 |
| 显存 | 24 GB 封顶 | 40/80 GB，还有 NVLink 卡间互联 |
| 散热/噪音 | 风冷偏吵 | 被动散热需服务器风道 |
| 适合 | 单卡微调/推理：本课程全部需求 | 全参训练、超大模型：用不到 |
| 限制 | 驱动对数据中心部署有限制条款 | 贵 |

结论：个人 24GB 消费卡能覆盖课程 100% 的需求；A100 级别只在租云时按需选用。

### 2.3 二手市场注意（3090 24G 是热门二手选择）

- 3090 矿卡/长时间高负载卡风险高：显存虚焊、鼓包。买前谈好退换。
- 收货必做拷机：GPU 压力测试跑 30 分钟以上，观察显存报错与温度（工具任选，如 gpu-burn 类
  开源压测）。
- 查保修剩余与是否拆修过；个人送修凭发票。
- 显存同样 24G 的还有 4090D 等，具体型号与价格随时变动，入手前再查行情。

## 3. 云 GPU：以 AutoDL 为例的完整流程

国内按时租卡的常用平台之一是 AutoDL（同类平台还有多家，流程大同小异；界面与规则随时更新，
**以平台页面为准**）。

### 3.1 租用全流程

```
1. 注册/实名认证（学生认证常有优惠）
2. 创建实例：
   - 选地区（离你近的、有货的）
   - 选卡型：毕业项目选 RTX 4090 24GB 档
   - 选镜像：平台预置的 PyTorch 2.x + CUDA 12.x 环境（省去自己装驱动的痛苦）
3. 连接：网页版 JupyterLab / VSCode 远程 / ssh（平台给出命令与密码）
4. 传数据（见 3.2）
5. 跑训练（阶段 5 L05 的完整操作链）
6. 收工：把产出（LoRA 权重/日志）下载或转存平台网盘 → 关机停止计费
```

### 3.2 数据上传的实用姿势

- 小文件（脚本、json 数据集）：ssh 的 `scp`/`rsync`，或 JupyterLab 直接拖拽。
- 大文件（基座模型权重）：优先在实例内用 `HF_ENDPOINT` 镜像直接下载（比上传快）；
  平台一般还提供网盘中转与公开链接下载功能。
- 记住原则：**数据集小（MB 级）上传，模型大（GB 级）现场下**。

### 3.3 计费与省钱

- 按量计费（元/小时）vs 包日/包周包月：包时段单价更低但闲置也在烧钱——调试期用按量，
  跑确定性长任务再考虑包时段。
- 「无卡模式」开机：只保留磁盘、不占 GPU，用来整理数据/传文件，费用极低（以平台规则为准）。
- 关机 ≠ 数据删除：磁盘保留一般收费很低，但**重要产出要及时转出云主机**，防止误释放。
- 竞抢型实例更便宜但可能被更高出价者抢占，跑长任务前想清楚。

### 3.4 成本测算表（毕业项目量级）

假设：QLoRA 微调 7B，数据 500~2000 条，跑 1~3 个 epoch：

| 项目 | 估算 |
|---|---|
| 单次训练时长 | 1~6 小时（数据量/序列长度/epoch 决定） |
| 4090 档按时价 | 数元/小时量级（以平台实时价为准） |
| 单次训练成本 | 约 10~30 元 |
| 全项目（含试错、多次实验、评估、部署演示） | 约 30~100 机时 → **100~300 元量级** |

结论：**毕业项目的算力成本约等于一顿聚餐**。这也是「先租后买」的底气。

## 4. 算力决策 Checklist

逐条打勾再下单/开机：

- [ ] 我的任务档位是什么？（只推理 / QLoRA 7B / LoRA 7B）对应显存多少（L04 公式）？
- [ ] 现有设备是否够用？（笔记本 CPU 能否先用 0.5B 走通流程再谈算力？）
- [ ] 数据是否敏感、能否上传云端？
- [ ] 每周预计用卡几小时？>20 小时且持续 3 个月以上再考虑买卡。
- [ ] 选云：卡型显存 ≥ 需求 + 20% 余量；镜像带 CUDA/PyTorch；地区有货。
- [ ] 训练脚本是否先在小模型/CPU 上空跑通过（避免租着卡调试）？
- [ ] 产出物（权重/日志）的下载路径想好了吗？
- [ ] 长任务前设了关机闹钟吗？（忘了关机=白白烧钱）

## 5. nvidia-smi：读懂你的卡

```bash
nvidia-smi                 # 一次快照
nvidia-smi -l 1            # 每 1 秒刷新（训练时挂着观察）
nvidia-smi --query-gpu=timestamp,memory.used,memory.total,utilization.gpu,temperature.gpu --format=csv -l 5
```

关键读数（训练时盯这几行）：

| 字段 | 含义 | 怎么用 |
|---|---|---|
| Memory-Used / Total | 显存占用/总量 | 距离 OOM 的余量；爆显存的前兆是快速逼近 Total |
| GPU-Util | 计算利用率 | 长期 <50% 说明数据加载或小 batch 拖后腿（L06 调优会讲） |
| Temp / Power | 温度/功耗 | 持续 80°C+ 要改善散热；功耗上不去=没吃满 |
| Processes | 占卡的进程 | 「显存泄漏找不到谁占的」就查它 |

常见误读：**Util 100% 不等于高效**（可能是频繁小 kernel 空转）；显存没满也不等于还有余量
（训练中激活随 batch 波动，峰值才致命）。所以观察显存要看**峰值趋势**而非瞬时值。

> 🍿 彩蛋｜租卡经济学：闲时卡便宜、热门卡型要抢、大数据集上传要走对通道……租卡平台（如 AutoDL）的生态像极了早年的合租服务器。资深炼丹师都有一套省钱心得——今天你自己也会算这笔账了。

## 小结与自测

1. **Q：算力决策的第一原则是什么？**
   A：先按任务档位用显存公式算需求，再选资源（显存优先），最后按使用频率决定租/买。
2. **Q：7B QLoRA 微调推荐什么卡？为什么？**
   A：16~24GB 级（云 4090 或本地 24G 卡）；QLoRA 实际占用 6~10GB，24G 卡留足 batch/长度余量。
3. **Q：云上「大文件现场下、小文件上传」指什么？**
   A：基座模型（GB 级）在实例内用镜像直接下载更快；数据集（MB 级）用 scp 上传。
4. **Q：毕业项目的算力成本量级？**
   A：约 100~300 元（30~100 机时 × 数元/小时，含试错）。
5. **Q：GPU-Util 长期不满说明什么？**
   A：存在瓶颈（数据加载慢、batch 太小等），算力没被喂饱——先看利用率再谈换卡。
