# 阶段 5：微调实战（全程核心）

> 建议总学时：25~30 小时（10 课 + 毕业项目实操）
> 前置：阶段 4 全部完成（会跑推理、会算显存、已定算力方案）
> 产出：一个由你亲手完成「数据构建 → QLoRA 训练 → 评估对比 → 部署 API」全流程的定制模型

## 这个阶段解决什么问题

阶段 4 结束时你「会用 LLM」；这个阶段结束，你「会造 LLM 应用里属于自己的那一层」。
这是整个学习路线的终点站：**独立完成大模型微调全流程**。

路线设计逻辑：原理（L01~L03）→ 工具与数据（L04 与 L02）→ 实操主线（L05~L06）→
质量关（L07~L08）→ 落地（L09）→ 毕业项目（L10）。

## 阶段目标（学完应能）

- [ ] 讲透 LoRA/QLoRA 原理（为什么低秩增量有效、QLoRA 省在哪），能白板推导显存构成
- [ ] 独立构建并清洗一份 500 条以上的高质量指令数据集
- [ ] 用 LLaMA-Factory 完成 QLoRA 训练、导出合并、对话验证
- [ ] 设计「微调前后对比」评估实验并输出对比报告
- [ ] 把微调模型部署成 API（Ollama 私有部署或 vLLM 服务化），并用 Java 接入

## 毕业项目（三选一）

三个项目难度相当、考察点相同（全流程），按兴趣选：

| 项目 | 一句话 | 特色考察点 |
|---|---|---|
| Java 代码助手 | 微调一个懂你们团队规范的 Java 问答/注释/解释助手 | 发挥你的领域优势，数据合成思路最清晰 |
| 领域客服 | 某垂直领域（如运维、教育、电商售后）的定制客服 | 语气/流程类行为塑造，评估表设计 |
| 风格化写作助手 | 模仿特定文风（如某类公文、某作家风格、自媒体体） | 风格评估的主观性处理，数据风格一致性 |

**统一里程碑**（L10 详细展开）：

```
选题 → 数据 500 条+（构建+清洗）→ QLoRA 训练 → 评估对比报告 → 部署 API 演示
```

**验收标准**（五条，缺一不可）：

1. 数据：≥500 条清洗后的训练数据 + 清洗脚本 + 数据说明（来源/配比/质量把控手段）
2. 训练：完整可复现的训练配置（命令/yaml）与 loss 曲线截图
3. 评估：封存的评估集（微调前已隔离）+ 前后对比报告（人工评分表或 LLM-as-judge）
4. 部署：模型可通过 HTTP API 被调用（Ollama 或 vLLM），附调用示例（curl 或 Java）
5. 复盘：至少记录 2 个你踩过的坑及解决过程

## 学习建议

- **L02（数据）比 L05（训练）重要**。微调的成败 80% 在数据，请把最多的时间投给数据。
- L05 是第一个「全流程可照做」的实操课，建议用 1.5B 模型 + 小数据先空跑一遍再上 7B。
- 毕业项目从 L02 就应该开始攒数据，不要等到 L10 才动手。
- 所有命令以官方文档为准，版本迭代快；讲义给的是流程与典型示例。
