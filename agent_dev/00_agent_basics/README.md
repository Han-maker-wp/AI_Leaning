# 阶段 0：Agent 开发地基（5 课）

> 前置：主线 00 阶段的 Python 基础（函数/类/uv 够用即可），无需任何 AI 开发经验。
> 本阶段回答一个问题：**你每天在用的那些 Agent 功能，拆开来看到底是什么？**

## 阶段目标

- 能画出 Agent 的四要素解剖图（LLM / 工具 / 记忆 / 循环），并把用过的产品功能逐一对应到构件
- 会用 uv 管理 Agent 项目，用环境变量安全注入 API key
- 裸用 openai SDK 完成对话调用、多轮 messages 维护、流式输出，说清 token 与计费
- 用「约定 + Pydantic 校验 + 容错解析」三层防御拿到可靠的结构化输出
- 用 asyncio 并发批量调用，处理好速率限制与指数退避重试

## Checkpoint：命令行 AI 助手

综合本阶段全部内容，写一个 `assistant.py`：

1. **多轮对话**：维护 messages 列表，`exit`/`quit` 退出；system prompt 定义助手人设（L02/L03）
2. **流式输出**：回答以打字机效果逐 token 打印（L02）
3. **结构化命令**：支持用户输入 `/summary`，让模型把当前对话总结成 JSON（含 topics 列表、turns 数、mood 字段），用 Pydantic 校验后再格式化打印；解析失败要有容错与重试（L03/L04）
4. **工程底线**：API key 走环境变量；主循环包在 `if __name__ == "__main__"`；异常有友好提示不裸抛栈

验收口径：能连续对话 5 轮不丢上下文；`/summary` 输出通过 Pydantic 校验；断网/无 key 时给出明确指引而非栈溢出。做完交给导师验收（「检查我的 Agent 作业」）。

## 阶段验收标准

- 四要素图能默画，并给每个要素举一个你用过的产品功能作例
- 说得出：为什么 API 是无状态的、token 为什么是计费单位、SSE 和 WebSocket 的区别
- 结构图（L04）与并发图（L05）能不看讲义白板重写主干
- 通过上述 checkpoint 项目
