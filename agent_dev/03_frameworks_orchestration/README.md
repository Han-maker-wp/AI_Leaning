## Checkpoint：用 LangGraph 重构阶段 1 的迷你 Agent

阶段 1 你用 `while True` 手写过工具调用循环。本阶段结束时，把它重构成 LangGraph 图：

1. **状态显式化**：对话历史、工具调用记录、循环轮数进 `TypedDict` 状态对象，不再是散落的局部变量
2. **条件边**：模型要求调工具 → 走 `tools` 节点后回到 `agent`；模型给出最终回答 → 走 `END`。用 `add_conditional_edges` 表达，删掉 while
3. **循环上限**：加一个"超过 N 轮强制收敛"的节点，防止失控循环
4. **human-in-the-loop**：对高危工具（如发邮件）插入人工确认中断，用 checkpointer 支持中断后恢复
5. **对比报告**（写进学习笔记即可）：重构前后各 50 行核心代码的可读性、调试手段、加新工具的成本

验收口径：`python L03_langgraph_demo.py` 能跑通你自己改的版本；能口头说清"图里每个节点、每条边对应裸写版的哪段代码"。重构后运行行为与裸写版一致（同样的问题、同样的工具选择路径）。
