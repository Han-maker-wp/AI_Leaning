# 阶段 4：工程化与毕业项目（5 课）

> 前置：完成阶段 3（编排已上过手，选型观已建立）。
> 本阶段回答工程化的最后一问：**怎么让一个"能跑的 demo"变成"敢上线的服务"？**

## 阶段目标

- 会给 Agent 加三件套：结构化日志、调用链追踪（tracing）、成本与延迟统计
- 会建评估集、写 LLM-as-judge、把 evals 接进回归测试，并给出上线判据
- 理解 prompt injection 与工具滥用的攻击面，会做权限最小化与数据脱敏
- 会用 FastAPI 把 Agent 封装成 HTTP 服务（含 SSE 流式），并能用 Java HttpClient 对接——回你的主场
- 完成毕业项目：需求 → 设计 → 实现 → 评估 → 部署全流程

## Checkpoint：毕业项目（本阶段即毕业验收）

三选一：个人知识管家 / 自动化办公 agent / 领域客服。统一里程碑与验收标准详见 `L05_毕业项目.md`。一句话概括验收口径：

> 一个陌生人拿到你的仓库，按 README 三条命令内跑起来，看到它回答至少 10 个验收问题中的 8 个达标，并能打开一份包含延迟与成本统计的运行报告。

## 阶段验收标准

- 可观测：任一次回答能回答"调了几次模型、花了多少 token、每段耗时多少"
- 评估：有 ≥20 条的评估集，judge 与人工抽检一致率 ≥80%，改动有回归记录
- 安全：高危操作过人工确认或白名单；日志与 LLM 请求中无未脱敏敏感数据
- 部署：FastAPI 服务含流式端点；能演示用 Java 客户端完成一次完整调用
