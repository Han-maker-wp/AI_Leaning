# 如何使用这套资料学习（Agent 开发轨道 · 必读）

这是 `agent_dev/` 轨道的使用说明，与主线 `HOW_TO_LEARN.md` 同一套玩法。你已经用了一年 Agent 产品，本轨要做的只有一件事：**把「用过」变成「会造」**。

## 一、资料怎么构成

```
agent_dev/
ROADMAP.md      → 本轨地图：阶段、周计划、验收标准（先通读一遍）
PROGRESS.md     → 你的进度表：26 课 + 5 个 checkpoint，学完一课勾一课
HOW_TO_LEARN.md → 本文
GLOSSARY.md     → 术语表：约 40 条，看不懂的词来这里查人话解释
STORIES.md      → Agent 领域真实故事集（换脑子的下饭读物）
00_agent_basics/          → 阶段目录，每个目录里：
  README.md       阶段大纲 + 验收标准 + checkpoint 项目规格
  L01_xxx.md      每课讲义 ← 你的主要学习材料，按序号读
  code/           配套可运行代码（多数支持离线 mock 模式，无 API key 也能跑）
notes/          → 还是那个原则：你自己的笔记我不动
```

## 二、每一课的学习循环（建议节奏）

1. **读讲义**：通读 `L*.md`，重点是「为什么这样设计」——本轨讲义默认你工程直觉在线，讲概念都往你熟悉的 Java/Web 世界上靠
2. **跑代码**：把讲义和 `code/` 里的代码亲手跑一遍，改改参数看结果变化（mock 模式没有 key 也能跑；有 key 换真模型）
3. **做练习**：每课末尾 2-4 道，**先不看提示自己写**，卡住了再看提示
4. **交导师批改**：跟我说「检查我的作业」，我会读你的代码并点评
5. **自测**：讲义末尾的自测问题，能口头答出来才算学完

每周 4-8 小时 ≈ 每周 2-3 课 + 练习，checkpoint 周会重一些。

## 三、对我说这些话（指令速查）

沿用主仓库协议；**两轨并行时加上「Agent」前缀**区分：

| 你说 | 我做 |
|------|------|
| 「开始 Agent 第 X 课」/「Agent 轨道继续」 | 按本轨 PROGRESS.md 带你学下一课 |
| 「Agent 这节不懂，再讲细点」 | 换角度、换例子重讲（常配 Java 类比） |
| 「检查我的 Agent 作业」 | 读你的练习代码，批改讲评 |
| 「Agent 出题考我」 | 针对本轨已学内容出题 |
| 「给我讲讲 XX 概念」 | 随时答疑，不限进度 |
| 「更新 Agent 进度」 | 勾掉本轨 PROGRESS.md 里学完的课 |

只学这一条轨道时，省掉前缀直接说「继续」即可。

## 四、本轨特有的学习原则

- **手写优先**：阶段 0-2 全程不用框架。不是反框架，是只有手写过循环的人才知道框架在封装什么、何时帮倒忙（阶段 3 会回收这个伏笔）
- **mock 也能学真本事**：`code/` 里的脚本大量用「条件分支模拟模型响应」来讲机制——协议和循环逻辑是真的，换成真模型只需改一个函数。别嫌 mock 低级，考试考的是循环怎么写
- **安全习惯从第一天**：API key 永远走环境变量；文件工具永远有边界；高危操作永远要确认。讲义里反复出现，请形成肌肉记忆
- **疑问不过夜**：讲义卡住立刻问

## 五、每周节奏建议

- 周中（工作日）：每天 1 小时左右，读讲义 + 跑代码
- 周末：集中 2-3 小时做练习 + 我批改 + 补答疑
- 每阶段末有 checkpoint 项目，通过后进入下一阶段；checkpoint 做完记得让我验收

## 六、API key 与花费

本轨默认你有一家「OpenAI 兼容端点」的 API key（OpenAI 官方或国内外任一兼容平台均可），用环境变量注入，格式见 00 阶段 L01。**绝大多数代码有无 key 都能跑**：离线 mock 覆盖全部核心机制，真实调用只占少数课。花费量级为对话级小请求，具体单价以各平台价格页为准。
