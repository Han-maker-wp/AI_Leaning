## 各阶段详情与验收

### 阶段 0：Agent 开发地基（第 1-2 周）
**目标**：把「用过」变成「会调」——理解 Agent 四要素，裸 SDK 完成 API 调用、流式输出、结构化解析、异步并发。
课程：Agent 解剖与工程化 → LLM API 实战 → 提示工程（开发者视角）→ 结构化输出 → 异步与并发。
**验收**：独立完成命令行 AI 助手（多轮对话 + 流式 + 结构化输出），并能说清 token 计费与速率限制的处理方式。

### 阶段 1：工具调用（第 3-4 周）
**目标**：掀开 function calling 的底牌——模型请求、代码执行、结果回填的完整循环，工具设计、记忆、安全边界。
课程：手写 FunctionCalling → 工具设计学 → 多工具编排与 ReAct → 记忆与状态 → 沙箱与文件工具。
**验收**：不用任何框架手写迷你 Agent loop（计算器 + 文件读写工具），含错误处理、轮数上限与安全边界。

### 阶段 2：检索增强 RAG（第 5-6 周）
**目标**：掌握 RAG 全链路：分块、embedding、向量检索、混合检索与 rerank、评估与工程化。
课程：RAG 全景 → 文档分块 → 向量检索 → 检索质量 → RAG 评估与工程化。
**验收**：个人知识库问答 agent（本地文档 → 检索 → 带引用回答），配 20 条以上评估集并算出 hit rate。

### 阶段 3：框架与编排（第 7-8 周）
**目标**：手写过了再上框架——LangChain 核心抽象、LangGraph 状态机、MCP 协议、多 Agent 模式，形成自研 vs 框架的决策清单。
**验收**：用 LangGraph 重构阶段 1 的迷你 Agent（条件边、循环上限、human-in-the-loop）。

### 阶段 4：工程化与毕业项目（第 9-10 周起）
**目标**：从 demo 到服务——可观测、评估回归、安全加固、FastAPI 部署（Java 对接主场），然后毕业。
**验收**：毕业项目三选一（个人知识管家 / 自动化办公 agent / 领域客服），走完需求 → 设计 → 实现 → 评估 → 部署全流程。

## 开工前的准备

1. **Python 环境**：Python 3.10+，工具链用 uv（主线 00 阶段已装好；命令忘了见主线 `00_python/L06`）
2. **API key**：任选其一——OpenAI 官方，或任意「OpenAI 兼容端点」服务（国内外多数大模型平台都提供兼容接口）。本轨大部分代码**提供离线 mock 模式**，没有 key 也能学完核心逻辑；有 key 体验更完整
3. **花费预期**：本轨涉及的真实 API 调用均为对话级小请求，量级很小；具体单价以各平台价格页为准，不猜数字
4. **读一遍** `HOW_TO_LEARN.md`（怎么用这套资料）和 `GLOSSARY.md`（遇到生词随时查）
